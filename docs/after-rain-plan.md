# 《心动在雨停之后》完整影游策划

## 一句话

一位纪录片摄影师回到海边城市，在旧影院最后一个营业月里，与四位成年人拍摄一部关于“留下”的电影。如何工作、怎样靠近彼此、哪些画面可以公开，由玩家决定。

## 主角和群像

- 姜予晴，25岁，纪录片摄影师。上个项目被剪成营销故事，她曾默许，失去同事信任；现在必须明确自己在拍什么。玩家控制她的表达与行动，不能替其他角色决定人生。
- 段言，28岁，现场音乐人。重视承诺，却习惯替别人把事情扛完。赴外地巡演的期限与影院音乐项目冲突。关系主题：陪伴与自由。
- 苏时安，27岁，品牌制作人。擅长合作谈判，面对上司与家庭期待过度维持体面。他负责资金，也承担收回预算的风险。关系主题：被看见与被使用。
- 顾砚，30岁，急诊医生、社区口述史志愿者。不善于承诺时间，擅长在危机中处理具体事情。自己照护父亲的责任影响关系。主题：可靠与边界。
- 周嘉禾，25岁，独立游戏开发者。将影院旧设备改造成互动地图。他怕作品被误解，常把失败藏在玩笑里。主题：共同创作与独立人格。
- 仲溪，29岁，纪录片制片、主角的前搭档。对主角有真实的失望，也有自己的资金与创作困境；独立事业结局的重要伙伴。
- 沈乔，25岁，记者、主角好友。想调查更新项目的程序，却不愿让友情成为索取素材的理由。
- 林老师，66岁，影院放映员，主角外婆。希望留下电影，也不愿被拍成衰老的符号；她是有主动决定的参与者。

## 故事规则

海岸城市“澄海”，雨季，旧街区影院“海声”。影院因安全改造暂时停业，商业方计划把它改成体验店。社区有不同意见：保存记忆、改善生活、租金和工作。不是一个坏人对抗一群好人。主角有30天、有限预算，需要获得当事人同意并完成首映。感情不能解决所有现实问题。

第一章不先发满屏设定，用返城、器材事故、影院试片和一次项目谈判建立人物。旧误会只露出具体反应，随后通过事件揭示。每章有温柔日常、工作行动、关系摩擦、一个不可撤销的现场选择与余韵。

## 十章的戏剧骨架

| 章 | 共同事件与主要问题 | 分支与延后结果 |
| --- | --- | --- |
| 1 雨停之前 | 返城；接到30天拍摄委托；决定拍摄承诺 | 拍摄授权、项目立场、首次互信 |
| 2 一起把灯打开 | 试拍和第一次小型展映；四位角色在同一现场协作 | 时间分配、信用与交片质量；认识角色并非直接进入恋爱 |
| 3 镜头以外的人 | 探访工坊、医院、品牌公司、开发工作室 | 哪些私人经历可以公开；明确边界后的关系变化 |
| 4 没有拍下来的那一晚 | 台风停电；素材备份与社区安置发生冲突 | 能否协作；选择带来的实际损失；消解旧误会的一部分 |
| 5 体面和真心 | 粗剪被要求修改；旧项目事实被好友发现 | 解释或道歉，修复合作；资金和表达不能全取 |
| 6 留一张空椅子 | 公开试映；每个人都有离城或留下的机会 | 明确关系意向，选择主要路线或独立事业线 |
| 7A 音乐停下之后 | 段言巡演前夕；共同完成演出 | 支持离开／要求留下／坦诚安排异地 |
| 7B 契约之外 | 苏时安换岗与投资退出 | 不越界使用关系；署名和承诺 |
| 7C 没有标准答案的照顾 | 顾砚照护父亲与职业疲劳 | 互助而不替代照护；允许拒绝 |
| 7D 未发布的版本 | 周嘉禾作品上线与团队矛盾 | 鼓励公开不等于替他说话；共同创作协议 |
| 8 彼此的日常 | 四路线各自的约会、朋友与家庭相处 | 亲密与日程，矛盾发生在真实生活里 |
| 9 我想要的生活 | 各自面临一个去留决定 | 不用好感值消除价值差异；可和平分开 |
| 10 雨停之后 | 纪录片首映、工作收束、关系结局 | 四角色各三结局＋独立事业结局；事业结果由共同线历史决定 |

独立事业线7—10也有完整剧情，不能变成恋爱失败后直接弹出的失败提示。

## 玩家操作和演出

摄影机视角与人物对话交替：层叠场景、角色立绘、缓慢推拉镜头、光线和雨滴、声场与字幕。镜头和配音按实际对白运行。没有强制等待，允许随时手动推进。

选择约三种：对话表达；现场观察后决定拍什么；手机上回复和安排见面。拒绝某次邀约仍有对应关系反应。选择可改变下一镜头、当章场景顺序、以后可用合作方式或结局条件。界面以叙事语言展示已发生的关系事实，数值用于系统计算而非向玩家宣称“加三点就相爱”。

手机：联系人、消息、通告日历、摄影笔记。主菜单：继续、重新开始、章节与分支、角色关系、回忆册、存档、设置。演出页：自动、仅跳过已读、回看、手机、分支、存读档、退出。**用户后续明确要求竖版：以9:16竖构图为主，桌面居中呈现竖屏电影窗口。背景补做原生竖构图，人物、字幕、选择与手机页面按竖屏设计，不能仅把横屏缩小。**支持键盘。

## 状态与存档

四个人分别记录信任和边界；项目记录素材、资金、授权、团队协作。旗标记录具体承诺。所有状态变化绑定选择，仅执行一次。回溯使用历史快照，必须还原旗标和资源。回看已解锁场景可继续产生新的路线；全局已读、CG和结局收藏保留。

三手动槽＋自动存档；版本化校验；导出与导入；读取坏存档不能清空有效进度。未制作的下一章显示继续制作状态，不能跳转到虚构的“通关”。生产审计独立于玩家页面。

## 原创图像与声音生产

图片生成：一张群像基准图；八名角色及表情；18个主要地点的昼夜、雨晴变体；每路线至少三张关系CG与首映CG。统一成年人物外观和海滨雨季色调，背景与立绘独立以支持镜头演出。所有最终文件存入本项目，提示词入清单。

实际配音按对白生成并记录字符摘要、时长与声音分配；不冒充真人演员。环境声和轻音乐通过原创程序音轨生成。自然停顿短暂，有减弱动效与音量设置。因音频生成未完成的场景以字幕游玩并明确记录缺项。
