# 晴岚守卫：剧情策划

晴岚群岛的守望晶核失去调谐，形成具象的雾灵与失控石偶，挡住人们往来的道路。玩家带领守卫队巡行六区，战斗净化晶核，重新建立区域的联系。不是矿务经营，也不是动物森林生活模拟。

六区：晴岚草原、潮光遗迹、赤陶峡谷、雪铃高地、翠镜庭院、星港圣坛。每区四个剧情节点，依次在5/10/15/20关解锁：遭遇当地问题、了解敌人机制、队友完成协作、区域首领净化。角色面对的是挑战和误会，败战不会让居民死亡，也不会因玩家离开恶化剧情。

十二位英雄为原创角色：盾卫阿洛、枪卫岚音；剑士赤羽、拳师陶陶；破甲师杜衡、雷锤米洛；风术师星芽、冰术师凝霜；弓手青禾、火铳夏烛；医师苏铃、祈愿师月白。人物技能与章节问题有关，获得英雄即展示简单配合示例。

每章约100字，战斗后轻提示，可随时手账阅读；不强制播放阻塞挂机。剧情图由图片生成实现，每区域一张独立主场景作为四章的共同插图，明确为六张图；角色另作原创图，不使用竞品角色。场景色彩明亮温暖、造型圆润，战斗击退以光屑消散表现。

最终在星港完成全队协作，晶核恢复，群岛重新通航。结局后六地图可回访、训练和挑战首领。长期系统不清零。
