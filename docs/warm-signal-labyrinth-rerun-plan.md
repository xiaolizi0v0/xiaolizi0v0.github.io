# 记忆迷宫 · 常驻复刻与归档

日期：2026-10-12。版本：`20261012-labyrinth-rerun-2`。本轮修正卷一把常驻入口误做成永久开放活动的问题；未增加空白历史卷或声称所有卷册已经完成。

## 研究依据

[台服2021公告转载](https://forum.gamer.com.tw/Co.php?bPage=0&bsn=33645&sn=14512&subbsn=3)说明常驻入口、随主线获得首次开启资格、命运骰子在票房商店兑换、同一时间只开一期、持续10天、复刻不重新开放迷宫探索，以及碎晶和照片保留。该页署名来源为官方，但本次获取的是社区转载，不能视作当前国服统一规则。

[2020常驻介绍](https://wap.gamersky.com/news/Content-1288652_2.html)交叉支持五个历史卷、随主线获得权限及票房商店兑换道具。[日服历史整理](https://gamerch.com/evolxlove/289945)写明每月兑换一次、月初5:00恢复次数，同时含日服特定的道具使用期限。[其他地区攻略](https://hobbigame.com/otomegame/戀與製作人-攻略-專區/活動/)存在“至月底”及复刻碎晶价格变化的描述，资料并不统一。

因此本项目明确采用10天开放窗口；500奖章、每月1日上海5:00一次、骰子永久保留是当前项目的具体安排，并不冒充所有发行地区一致的运营配置。现有150钻石/碎晶价格继续作为项目设定。界面沿用上轮实际查看过的宫殿/探索双入口和暖色原创卡面，没有把原作图片放入游戏。

## 玩家流程

1. 主线2-12之后，手动免费开启卷一首次旅程。首次旅程包含宫殿与探索，开放10天；这是将首开体验接入当前六章主线的项目安排。
2. 顶部持续显示剩余天数和时分秒，卷册面板显示明确的上海时间截止日期。只在状态变化时重绘页面，倒计时不会每秒清空滚动位置。
3. 票房商店新增独立的命运骰子商品。消耗500票房奖章，获得1枚；当月只能兑换一次。普通商品的每日重置和付钻刷新不会恢复骰子库存。兑换先确认，取消不消费。
4. 本期进行中不能再次开启。到期后用1枚骰子开启10天复刻；刷新、返回和重复确认都不能叠加或延长当前窗口。
5. 复刻只开放宫殿回忆、购买碎晶与照片换卡碎片。探索、补探索次数、照片换请帖及首开请帖领取均关闭；不重发180请帖、不恢复次数，也不刷新商品限额。
6. 到期保留碎晶、照片、碎片、已有羁绊、探索额度/星级/进度、纪念币、商品库存、故事书签和已领取记录。宫殿显示归档与重开入口，探索显示保留进度。已解锁故事可继续阅读/重温，够数的已有碎片可以合成，已有纪念币可以兑换原本有限的补给。这些归档便利操作是本项目安排。

## 存档与事务

`labyrinth`升级为v2，新增`opening`：期数、开始与结束时间、首开/复刻类型、已观察到期标记、骰子持有/购买/消耗及兑换月份记录。骰子满足“购买减消耗等于持有”，购买数等于唯一递增月份数；期数减一等于消耗骰子数。窗口长度必须恰为10天。

无迷宫进度的旧档只补空字段。已入场v1旧档保留原入场方式及全部收支，以旧档最后一次迷宫操作时间作为首期起点，结束时间为该时间加10天；不会因每次加载重新获得10天，也不自动发骰子、钻石、请帖或卡。若这一窗口已过去，加载时直接归档，资源照常保留。

每次操作核对迷宫版本号、当前时间与操作类型。兑换骰子额外核对确认时的月份，跨月旧确认不会扣奖章。游戏刷新观察到到期后，持久记录关闭状态和时间，倒退设备时钟不会重新激活该期。使用本机时钟的单机存档不等同于服务器签名与可信时间服务。
