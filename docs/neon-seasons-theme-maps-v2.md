# 四轮主题岛：装修、故事与永久收藏

2026-10-01。此次扩充依据既有v2活动策划，不改变七天时限、订单/生产资源来源、十二处费用、逐处领奖、永久收藏或存档字段。主题与故事为本作原创，不冒充原作活动名称和内部数值。

四轮保持同样易懂的十二步装修角色：小桥、花园、小径、六张长椅、街角铺子、串灯、小亭、餐桌、手作礼物、舞台、航灯、迎客门。不同主题使用独立地貌、路径、植被、物件配色与命名：春日薄荷花园、夏夜潮汐舞台、秋日枫叶邮局、冬夜雪中围炉。邮局主题的街角铺子是邮局，冬夜铺子是暖饮铺，避免图形和名称错配。

每处必须有自己的可辨认图形和未修/已修变化。草图、废弃木料、破损结构不能都由一栋通用小屋表示。地图上的小桥跨过水道，步道串起各处，铺子/小亭/舞台等保留可读轮廓；按钮使用实际地点名，完成后的地点仍可点开重读。

共四十八段地点事件，围绕同一轮活动递进：准备场地、留好安全通道、照顾慢来的人、一起庆祝、留下能再次访问的地方。装修后展示地点图与角色一句对白，奖励仍可手动领取；重读不能重复给奖。

永久收藏不只显示数字。提供四座岛的收藏入口，已完成主题可再次查看完整场景并重读十二处故事；未完成主题显示未收藏，不能在收藏界面花资源或修改当轮进度。当前轮与收藏回顾有清楚的标题和返回路径。

检查范围：四张地图的48种物件、每处前后变化、四主题全部正常资源完成、活动过期和再开后收藏可读、领奖防重复、坏数据拒绝；实际手机当前地图的地点点击、故事、奖励和返回。此部分通过不替代全游戏后期美术、小游戏、经济或全手机流程验收。

## 实现与验证

`theme-content.js`提供四主题、48处命名和独立文本；`theme-art.js`提供四张地貌与96个未修/已修物件SVG。地图功能物件为代码图形，剧情画面为imagegen原创插画：32处已有独立图，秋岛末4处与冬岛12处因生成额度限制暂复用其他已生成插画。完成后点开记事，永久收藏可重访地图；未收藏的四个入口禁用。

`node tools/neon-seasons/theme-playthrough.cjs`从既有正常完成状态继续，以生产、合并、自然恢复、合法仓储/出售与正式领奖完成余下三轮，不直接注入资源。追加6544次生产、172460秒虚拟恢复等待、零次体力购买；每轮12处装修、12层探险、10道菜与六档鱼分奖励通过，过期再开保留四岛收藏，第五轮回到春岛。96个物件SVG无重复、无非法值且均通过XML解析。此为规则可达性证据，不能换算真人时长。

实际390×844手机页读取春岛十二个正确命名的物件、首座小桥已修状态和生成剧情；未修节点/未收藏入口不会开放剧情。页面原有1/12进度保持。证据：`neon-seasons-screenshots/v2-theme-map.png`与`v2-generated-island-story.png`。
