# 松风小院：剧情策划（开发前）

内核：“照顾不等于催促。有人愿意在你离开的时间里，让灯继续亮着。”不是救世界、赢排名或治病，而是重新获得一点自主的日常。动物无惩罚性的情绪条；对白不评价玩家勤奋程度。

玩家收到一封没有催回日期的信，成为松风小院的临时看院人。信来自八位动物，大家轮流帮忙。以建设推动空间变化和人物日常，24章分四组，每章短正文与一句动物对白，可随时关闭。

角色：兔子米团（面包、慢慢来）；狐狸栗尾（茶、尊重边界）；小熊暖木（汤、允许疲惫）；水獭溪豆（莓果、喜欢收集）；鹿绒绒（花与布、允许不完美）；刺猬针针（手作、不必赶上别人）；猫头鹰晚灯（夜茶、安静陪伴）；浣熊阿松（修理、一起分担）。各3封关系来信，承接相识/分享/留下的位置，24份小心愿使用对应喜欢的料理/工艺。

第一组小院：扫开落叶、修门铃、摆长椅、补厨房、种菜、打开共用信箱。玩家发现动物并不等自己天天回来。

第二组溪畔：铺石路、洗野餐布、架小桥、留浅水观察位、挂风铃、搭溪畔餐桌。栗尾学会独自喝茶，溪豆不再把每一次发现都变成竞争。

第三组萤火林地：收起旧牌子、做夜灯、铺软垫、搭鸟屋、打开手作棚、举办无时刻表的茶会。针针的歪针脚保留下来，绒绒不必把花种得一样高。

第四组山顶茶亭：修阶梯、摆望远镜、铺屋顶、留窗边座、放回信册、点亮归家灯。最终不是大典，而是一封“你有空再来”的合写信。终章后仍可种植、布置和来访；无选择删除资源，结局只领一次。

场景美术：原创绘本动物、苔绿/奶油白/暖木棕/薄荷灰蓝，圆润低对比；保留可点击对象的轮廓与文字对比。场景图和角色使用imagegen，功能层由HTML/CSS呈现，生成图不嵌入按钮文字。任何交互目标有文字标签，画面不是一张不可操作的海报。
