## 页面与循环

城市入口 → 城市调查 / 人才市场 / 报道档案三个页签。顶部显示调查员等级、经验和勋章。地图中央搜索线索，右下领取每日报酬，地图下调整能力、查看四类课程卡并进入公司课程。

新玩家通过主线 3-1 后开放。旧存档保留原有城市新闻入口、公司勋章、资源和主线进度，不追发新系统奖励。调查不限每日次数，不消耗体力；搜索只从当前等级开放选题中抽取，可重新搜索。

能力采用独立编队，初始最多三张；调查 LV.3、5、7 分别增加一张，最多六张。允许少于上限的编队，必须为已拥有、不同的羁绊。调查力为 `floor(公司四维总和×0.5 + 选中羁绊四维总和×0.2)`；使用原始属性，不继承 24 小时挑战的损耗。进入时保存编队和调查力快照，调查结束前不允许改队。

调查分三个搜集阶段。每段十秒内点击三次，触发一个三选一问题；答对进入下一段，第三次答对后待发布。答错或搜集超时失败，可返回原线索重试。每次调查有唯一序号；过期点击、重复答案和重复发布均拒绝。截止时间为绝对时间，离开或刷新不会重置；问题页和待发布状态可续接。

发布才发奖：金币 `300＋选题序号×50`，对应课程卡 2，调查勋章 `2＋floor(选题序号/3)`，调查经验 `30＋选题序号×5`。每个选题首次另给钻石 20。报道档案保存最近二十次发布及六项永久完成记录。发布同时计入既有每日新闻任务。

## 等级、每日奖励与资源流转

调查八级经验门槛：0 / 60 / 180 / 360 / 600 / 900 / 1260 / 1680。称号从见习调查员到晴川见证者。

每日报酬于上海时间 5:00 更新，手动领取；调查等级 L 获得勋章 `8＋2L`、四种课程卡各 L 张。同一天升级不能重复领取。页面留在新闻页跨越更新时间时会刷新领取状态。

课程卡在公司课程页消耗，一张提升对应四维属性 15，不消耗金币和羁绊进化材料；提升后同时影响拍摄评分与调查力。调查勋章与公司采购使用同一个钱包，可以采购已有图纸、增效券、饮品，也可以聘用专家。

人才市场提供八位原创顾问，等级与价格逐步开放。聘用后出现在主线、拍摄副本及现有通用拍摄准备的专家下拉框；基础团队五人保留。新顾问基础评分为等级×85，匹配擅长主题另加25；每次培训花费当前等级×1200金币，最高30级。顾问不占大楼固定员工席位，也不计入24小时挑战评分。
