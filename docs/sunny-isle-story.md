# 晴岛夺核：剧情策划

六座漂浮岛曾用潮灯分享温暖。一次雾潮把无人照料的能量凝成雾兽，它们不断向周围借力，越膨胀越难停下。守望者铃带着共鸣铃出发；她可以拆开失序的连接，也可以让仍在运作的部件转而帮助岛屿。

故事解释主玩法的取舍：完全切断会让威胁停机，也让已经接管的光失去来源；保存与改变连接，需要辨别哪些部分值得留下。战斗发生在无生命的雾晶构造上，不伤害居民；玩家仍能获得破甲、击碎与反击的明确战斗反馈。

三位守望者：铃，巡灯人，擅长稳定攻击与观察；砚，潮石匠，偏向穿透拆解；禾，航路医师，偏向持续修复。角色故事不规定玩家必须选择某种策略。

|岛屿|视觉与结构主题|章节开始|首领后|
|---|---|---|---|
|晴芽岛|晨光、圆润草坪、短分支|铃发现雾兽的炮瓣仍听得见潮灯|第一盏灯恢复，居民学会为失序连接命名|
|蜜湾岛|柔蓝海岸、双能源|砚解释两条来源并不总能替代彼此|双潮兽散去，保留的光点进入航道|
|陶风岛|暖陶峡谷、护甲与中继|旧路被甲片封住，硬打消耗越来越大|甲壳退下，岩壁露出原本的色彩|
|绒雨岛|雨后蘑菇、修复与再生|禾指出修复也可能一直维持错误状态|修复雾兽平静下来，雨声变得轻盈|
|晚霞岛|粉金云海、覆写与容量|被接管的部件开始被雾潮夺回|覆写停止，守望者将不同的光留在一起|
|星眠岛|蓝紫星夜、多层供能|最后的雾兽承载所有遗失的连接|岛屿无需一个永远不休息的守望者也能亮着|

12段章节剧情，以六张图片生成的章节插画呈现。文字每段约100—180字，分屏阅读；剧情解锁后进入相册，自动战斗不被弹窗打断。首通会以轻提示引导查看。可以跳过或重看。

美术参考动物森林式的柔和、圆润、温暖与清晰材质，原创群岛、人物与雾晶形象，不复制原作角色与场景。游戏性仍以系统战斗为核心，剧情与治愈画风不替代玩法。
