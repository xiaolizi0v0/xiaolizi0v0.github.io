## 后续美术清单

统一奶油白、豆沙粉、浅金和柔绿，角色维持圆润 Q 版与柔和插画质感。背景同样走二维手绘方向，按街区制作独立店面、树木、花箱、设施和地面素材，替换当前 Canvas 简化绘图，避免角色精度明显高于环境。

骑行当前为现有站姿/朝向图片与二维自行车合成，尚无专门坐姿、握把、踩踏和后座帧。设施同样需补专用乘坐帧。后续直接制作这些 2D 素材及短帧动画，不再用三维模型补足。当前方向统一不等于全部美术达标。

新增图片应保持同一角色脸型、发型、服装与配饰，分开保存各套皮肤。帧之间统一身高及脚底锚点；动作以独立帧切换，避免把脸部或嘴部所在的大块图片压缩变形。至少检查正面、背面、左右朝向、合照和画面边缘。
