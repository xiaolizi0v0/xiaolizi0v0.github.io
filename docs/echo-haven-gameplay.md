# 晴岚回响：候选玩法草稿

状态更新（2026-10-08）：用户要求先广泛调研市场玩法。本文件退回候选研究，尚未通过方向筛选；其中内容规模是设想，不能当作已经制作的内容。当前研究与权威状态见market-gameplay-map.md、pine-haven-status.md。

核心循环：自动战斗→记录实际动作→保留四秒片段→改变重演方式→自动完成更难交战→获得永久成长与新回声能力。玩家用少量编辑改变之后的战斗，不必反复点击。

## 正式内容

六个区域，每区十二关，72关战役；每三关精英、每十二关区域首领。三种可免费切换的战斗风格：剑舞（连续近身范围）、重锤（破甲推开）、音刃（远程穿透）。九类敌人：追击、集群、厚甲、狙击、治疗、冲锋、召唤、护盾、首领。十八项永久研究，十二项装备成长。24个故事节点，每三关解锁；六个独立首领挑战，可回访区域训练。主线完成后继续训练和高阶首领。

## 自动战斗

一位守望者保护中央晶灯，敌人从地图入口进入。守望者按玩家“拦截/追击/护灯”的行为自动移动和攻击，普攻蓄满能量后自动使用风格技能。敌人会攻击英雄或晶灯，刺客优先晶灯，厚甲减少正面伤害，护盾敌有周期护甲窗口，首领召援与地面预告。每关三波，击败全部波次取胜。失败恢复英雄并转入已过关训练，收益仍来自真实战斗。

记录包含每个0.1秒逻辑步的角色位置、实际攻击事件、方向、半径与伤害基础比例。最近12秒滚动记录，片段四秒、40帧；可从最近战斗三个片段中选择，胜利也自动保留一个有效片段。最多保存12片段，玩家命名/删除，已装配片段不能被自动覆盖。没有片段时也能自然打过最初教学关。

## 回声决策

一到三个回声槽逐步解锁。槽选择真实记录，并设置：
- 重演方式：原位（照坐标）、镜像（左右翻转）、随身（相对现角色平移）。原位保留空间差异，随身有较低输出，不能成为无限制最优。
- 时机：0/2/4秒延迟，开场/敌群≥4/首领护甲破除/晶灯低于60%四种触发。每次四秒重演后冷却，后续会再次触发；不会每帧无限复制。
- 职责：打击（空间范围伤害）、诱敌（敌人可见并追击该回声）、守护（录下的攻击转为修复晶灯，消耗回声能量）。三职责均来源同一记录，不是固定召唤另一个英雄。

所有回声共享能量预算，能量由真人角色攻击与正常时间恢复，不能无限叠加。每槽显示实际命中/打空/保护/诱敌数据。研究逐步开放空间变换、第二/三槽、条件触发、职责、能量循环；新系统改变选择，基础等级增加只是辅助成长。

手动“留住刚才”保存当前最近四秒，不要求及时按，战后候选可重看；“放大回响”让能量足够且已冷却的回声提前执行一次，冷却限制，不凭空加资源。自动模式具备完整战斗能力。三套方案可保存和恢复。

## 长期与挂机

金币用于角色等级和装备，星砂用于研究；都来自真实击败/首次过关。离线最多24小时，与在线同一个引擎，资源与战役可推进。可开启自动强化并设资金保留额；自动片段保留用于观察，自动模式不替玩家覆盖已编辑策略。失败后可在训练升级，满足关卡重试条件自动再挑战，不让系统死循环白等。

设置包含暂停、1x/2x、自动推进、自动强化、静音、减少动画、电视伴随、导入导出。无广告/付费/抽卡、永久伤亡或强制清档转生。可随时读取剧情、图鉴、战报与机制帮助。

验收：72关可自然推进；每种敌情有可观察对策；回声打空与命中不是装饰；诱敌改变实际目标；原位/镜像/延迟有真实结果差异；在线/离线一致；失败训练能回到主线；片段来自实战而非预置特效；全部设置和存档可操作。数值通过不意味着真人已经觉得好玩。
