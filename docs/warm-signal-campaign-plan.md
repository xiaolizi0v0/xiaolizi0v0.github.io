# 主线地图、普通与精英拍摄策划

版本：2026-10-09 / campaign v1。入口 `tools/WarmSignal.html`，资源版本 `20261009-campaign-5`。

## 参考与证据边界

本轮阅读[历史新手说明](https://www.9game.cn/lyzzr/9688454.html)，实际打开并查看其中的[羁绊召唤界面图片](https://media.9game.cn/gamebase/ieu-gdc-pre-process/images/20240114/12/12/5a5e697c6614bac202506c8e6fdd4f0b.jpg)。图片显示顶部三张上阵卡、四维实力、中间确认、下方属性筛选与卡牌网格；本文据此重新组织拍摄准备。图片仅作研究，没有作为游戏素材。

该历史说明支持普通/精英切换、4-9门槛、剧情免体力、普通5/精英8体力、专家关键词后召唤羁绊，以及二星可重拍。它是2024年转载的早期流程说明，不能单独证明2026年原作全部现行细节。

[原作官方活动公告](https://evol.papegames.cn/news/719)列出精英关卡重置券，确认该道具存在；并不证明本项目的重置价格、次数和掉落率。[2017年第二章攻略](https://shouyou.3dmgame.com/gl/57222.html)列到2-18，也显示原作有2-5等拍摄节点。当前六章各18节点、剧情与拍摄交替是原创内容编排，尚未逐关复现原作编号与节点类型。地图的节点类别和章节切换来自文字资料，本轮没有取得同版本完整地图的清晰截图，不将地图外观称为像素级一致。

## 玩家流程和页面

主页「开始」→ 章节地图 → 阅读故事或选择节目 → 两次特殊事件 → 羁绊召唤 → 拍摄结算 → 重拍获得材料 → 培养 → 下一关。

- 地图占满竖屏。上方返回/规则、可点击补给的体力/金币/钻石、章节名称与左右切换；中间独立滚动的街景节点；下方章节星级、三个奖励箱、材料背包与普通/精英切换。
- 剧情使用暖粉心形，节目使用场记牌。显示编号、名称、星级、锁定和下一站；精英还显示每关今日余次。进入或完成节点后，地图定位到当前进度。
- 普通采用奶油杏色，精英采用暖玫瑰色雾面，沿用原创晴川街景。卡面统一调用已有等比裁切组件。
- 章节标题打开六章目录，显示每章星级；后续章按前章完成顺序开放。
- 拍摄概览展示三档分数、两项重点属性、消耗、首通奖励和掉落。二星后开放普通1/5/10次重拍，精英可单次或一次完成当日余次。
- 准备步骤一：两件片场事件，各选一个已聘用专家，展示两个关键词、匹配数和实际加分。
- 准备步骤二：顶部三张卡与四维实力，中间属性排序和推荐按钮，下方四列卡册，底部预计总分与固定拍摄按钮。
- 准备阶段不消耗体力，所选专家、卡牌和步骤自动保存；返回地图可继续或放弃。完成后将队伍用于普通拍摄，票房/调查等独立队伍保持各自设置。

## 章节内容

六章各9段剧情、9次普通拍摄，共108节点；每章另有10次精英拍摄，共60关。原创故事扩展了温室开拍、钟楼修窗、天台录音、档案采访、深夜剪辑和街区首映。剧情文本在 `campaign-content.js` 与 `content.js`，没有复制原作台词。

| 章 | 故事 | 普通拍摄主题 |
|---|---|---|
| 1 | 春天的第一封信 | 温室、街角、试映与日常短片 |
| 2 | 给明天留一扇窗 | 勘景、测量、访谈与钟楼纪事 |
| 3 | 听见夏天的回声 | 试音、合唱、采样与屋顶录音 |
| 4 | 故事之外的你 | 档案、采访、校对与旧信 |
| 5 | 月亮也会等你 | 烘焙、收店、夜晚回放与片尾 |
| 6 | 明天也在这里 | 首映、观众来信、直播与合照 |

普通3-1完成后开放城市新闻，5-1完成后开放24小时挑战。4-9完成后开放精英1-1；精英沿自身进度依次解锁。以前的公司/DIY首章门槛同步指向普通1-18。

## 本项目数值

以下是可调整的项目规则，不宣称为原作精确数值。

| 项目 | 规则 |
|---|---|
| 体力 | 剧情0，普通5，精英8；批量先检查足额资源与次数，一次扣款 |
| 评分 | 两项重点属性权重1，其余0.2；公司四维与所选羁绊分别求和取整，再加专家反馈 |
| 专家反馈 | 每次事件 `等级 × (30 + 45 × 匹配关键词数)`；两个事件可安排同一专家 |
| 星级 | 目标为一星，向上取整的1.15倍为二星、1.5倍为三星 |
| 重拍 | 至少二星，沿用已获得星级；不会自动把二星改成三星 |
| 失败 | 消耗单次体力，无成功奖励和羁绊经验，不推进进度、不占精英成功次数 |
| 每次成功奖励 | 金币 `450 + 120 × 章节索引`，心愿1，制作人经验25 |
| 首次奖励 | 普通拍摄钻石30，精英40；剧情钻石20/制作人经验20，重读不重复发 |
| 材料概率 | 每次独立判断，普通50%、精英40%，每次最多对应材料1份，可能零掉落 |
| 羁绊经验 | 手动拍摄每张20，重拍使用该关保存的最佳阵容；升级门槛 `60 + 20 × 当前等级`，未进化40级封顶、进化后60级 |
| 精英额度 | 每关每日成功3次，上海5点更新；次数按关卡独立保存 |
| 精英重置 | 三次用完后可重置，优先使用券；第1～3次30钻、第4～6次60钻、第7～9次90钻、第10次120钻，每关每天最多10次 |
| 星级箱 | 普通9/18/27星，精英10/20/30星；每档金币1500/3000/4500、钻石30/60/90、心愿2/4/6；精英末档另加重置券1 |

升星沿用四类材料。进化新增六位女生对应材料：春芽标本、城市蓝图、旧曲唱片、晴川剪报、月见配方、镜头日记。进化还需要10级、金币4000、星尘20；材料需求按N/NH/R/SR/SSR/SP/UR/ER为2/3/4/6/8/10/12/8份。材料与原有费用同时满足才扣款。既有已进化卡保持原状态。

材料背包和羁绊详情都可跳转到普通升星或精英进化材料的来源；未开放时明确显示门槛或前置关卡。旧关卡若没有留下原拍摄阵容，重拍仍给关卡奖励，但不能凭空补发羁绊经验；再手动完成一次即可建立阵容记录。

## 存档迁移和防重复

新增 `campaign.version=1`；旧档没有此字段时，将旧六节点章节迁移到18节点章节，每章旧节点0～5分别映射到新节点0/5/6/11/12/17。旧下一节点和旧星级一起映射。已越过的新插入剧情视作经过，不自动补发钻石；新插入节目没有星级，可再拍摄取得首次奖励。钱包、卡牌、其他玩法、已领取成就和日期都保留，不自动补领章节箱或精英奖励。

举例：旧主线下一节点2变为新节点6，即下一站1-7；旧1-2三星变为新1-6三星。旧6/13/25分别映射18/37/73，与首章、3-1、5-1的既有门槛一致。旧36完整通关变为108。迁移只执行一次。

准备用独立会话编号，拍摄后清空；旧按钮不能再次提交已经结束的拍摄。批量重拍与重置使用持久序号校验，跨日期或状态变化的旧确认不扣费。每日额度只向新日期刷新，时间回退不补领。星级箱按模式/章节/档位保存领取记录，普通和精英互不串账。

导入校验覆盖节点、已通关星级、章节箱门槛、最佳队伍与分数、准备阶段、拥有的卡牌/专家、经验范围、材料及次数上限；无效数据不会替换当前存档。

## 验收及剩余差距

完整游戏176项测试通过，其中本轮新增19项；语法和空白检查通过。受控测试覆盖全部108普通与60精英通关、所有旧进度边界、5点刷新、十次重置价格、券优先、经验封顶、进化扣减、无效存档和重复操作。受控测试的资源与时钟独立于玩家浏览器。

真实浏览器已从迁移后的1-7推进到4-9；普通1-2以单卡取得685分二星，五次重拍后仍为二星，扣25体力并使该卡升级。精英1-1/1-2实际三星，分别验证三次日限、30游戏钻石重置、当日余次重拍，以及城市蓝图进入背包和来源跳转。普通第二章9星箱领取后禁用。176项逻辑检查不能代替原作全部玩法验收，也不能把19项测试称为全游戏完整复刻。

当前仍缺：与原作逐关一致的完整章节/节点类型/素材掉落表、同版本地图外观对照、精确评分与养成经济、全部专家关键词库、完整长篇剧情/支线与专业演出、限时双倍掉落和后续主线活动。其他系统的历史活动、服务器社交、在线排行与运营内容继续按总研究差距补齐；总目标保持进行中。
