# 剧情插画制作与接入

依据用户要求，正式剧情画面统一改用内置 imagegen 生成的原创插画。封面与六位头像只作为人物和画风参考；不使用参考游戏素材。生成的是新画面，不修改参考图。

每张1536×1024图集包含四张独立768×512剧情画面，页面按象限显示，保持原图，不用代码重绘或裁切人物。计划52张图集、208个场景：8段家园、64段街区、60张活动故事、24张基础记忆、序章与3个结局，另含四座主题岛48段装修记事。每段按现有剧情的行动、地点和人物分别设计，图中文字由网页提供。

提示词源文件：`neon-seasons-story-image-prompts.cjs`；完整生成提示词与场景编号：`neon-seasons-story-image-prompts.json`。运行时映射为`tools/neon-seasons/story-images.js`。生成原稿保存在Codex生成目录，选用版本复制进`tools/neon-seasons/assets/story/`。

逐张检查四格边界、人物身份、动作、叙事对应；浏览器检查图片请求、手机比例、未收集卡的遮罩、剧情回放与存档。场景仅改变表现，不改变资源、解锁条件或奖励。

生成状态以运行时映射及资产清单为准。未生成的画面仍属于待办，不将规划数量报告为完成数量。
