# 松风小院：内核与实现策划（开发前）

## 情感内核

三个支柱：可以离开（无超时损失）；可以决定（作物、制作、招待、家具）；回来有变化（成长、旅行、朋友和建设）。观看氛围不消耗资源，沉浸和静音同等可用。让自动进展承担重复劳动、让玩家承担温柔的选择。

## 技术内核

新目录tools/pine-haven与独立PineHaven.html，独立存档键pine-haven-profile-v1。纯JS规则模型与DOM界面分离，所有计费先校验、交易后保存。整型物品计数、有限数值和固定ID集合严格验证；序列RNG持久化；读档失败尝试最后有效备份，无法恢复时明确提示，不静默覆盖损坏档。

时间按毫秒结算：货币存pendingCoins，花园按完整成熟次数与剩余时间结算；最长12小时，超过仅停止增加而不删既有积累。制作与旅行由绝对完成时间决定，奖励只在领取时给一次。倒拨时钟不回退stamp、不产生负收入；再次前进不重复同一时间段收益。所有自然结算先保存新基线，导入前验证；备份本地JSON，替换需确认，重新开始需确认并保留恢复备份。

不依赖服务器、数据库、第三方账号或假真人榜单。游戏静态资源随页面加载，断网时已加载内容仍可操作；不把普通网页初次加载称为安装包离线支持。浏览器关闭后的进展由下次打开结算。

规则边界：4作物槽、3制作位、1旅行位、6家具摆位。队列满/材料不足/锁定内容/重复领取一律不扣。事件ID是固定内容表项，无任意导入奖励。招待上限友谊12；愿望、来信领取和结局一次性标记。全部24工程/24愿望/24家具/20发现/24来信都有可追溯正常来源。

测试覆盖时间分块一致性、12h上限、倒拨、领取原子性、刷新恢复、导入损坏、防重复、正常全内容可达、手机界面主要交易与320/390/横屏。结果区分边界夹具、正常资源流程和真实浏览器证据。
