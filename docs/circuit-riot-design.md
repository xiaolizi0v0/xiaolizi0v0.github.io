# 回路暴走 / CIRCUIT RIOT — 研究与完整制作策划

2026-09-30。独立新游戏，保留既有《裂潮：霓虹清场》及其进度。继承炭黑、酸性绿、紫红、青蓝、斜切涂鸦与原创都市角色美术。2D 俯视竞技场，手机触控优先，电脑键盘同样可玩。

差异化结论：绘线、区域判定和回声分别有先例。目标是实现独立的“轨迹挂线 → 夺取弹幕 → 主动闭环清算 → 把回路留给回声重放”循环，且主要有效伤害必须由这套循环产生。有限样本不能证明与市面所有作品完全不同；验证的是相对所研究样本的具体行为差异。

## 二、核心战斗设计

玩家自动记录移动轨迹，轨迹最多保留一卷线的长度。穿过线段的敌人获得挂线印记，敌人弹丸触线后被截获，转为储能。移动本身不依赖自动枪械。

点击收线：用当前点与起点连接闭合轨迹，计算真实多边形与边缘；圈内 / 边缘敌人受到大量清算伤害，圈外已有挂线印记的敌人承受较低清算伤害。截获的弹幕增加爆发并生成返还弹丸。范围预览显示当前闭环与潜在目标数；短直线可以切断挂线敌人，绕圈能获得更高伤害和回路评分。

闭环面积、长度、接缝距离、截获弹数与玩家状态共同影响收益。无有效轨迹时收线不会消耗资源。有效收线消耗线能，击杀 / 捕弹返还资源，离开攻击也可缓慢回复。线卷满时自动执行一次收线或安全换卷，避免触屏超长轨迹失控。辅助自动收线可开启，但移动织线仍必须由玩家控制。

回声：保留最近有效闭环的真实坐标和能量，再次调用回声时在原位置复刻一次清算，不移动范围到当前敌人；鼓励诱敌回到曾经的回路。局内升级可以让回声延时、连续重放、吸引敌人、返还线能。

主动动作：收线、闪避（短时无敌并继续织线）、回声、倒带（沿最近轨迹快速回到起点，跳过中间碰撞并回收线）、超载（清算所有当前挂线并短时间补满线能）、治疗。最简单策略是移动绕群后收线；高手策略是接弹、在预警中织线、把首领引入旧回路。

## 三、内容与肉鸽

三种剪辑器（开局均可选）：锋线 / 折光 / 幽帧。分别偏好边界切割、弹幕截获、回声复制；每种有独立基础生命、速度、捕弹容量、回声倍率和技能视觉。

三种地图：地铁断层、电弧中庭、失真天台。每次由种子布置障碍、节点与敌人进场；保留可通行空间。章节八波，第 4 波精英，第 8 波首领。每波 24–52 秒，需完成清场配额；普通 / 过载 / 崩坏三档。三首领：断线者（切线禁区）、棱镜核心（弹幕与转向）、秒针暴君（延时印记与召唤）。有二阶段，所有高伤害均有预警。无尽每八波轮换首领与场景，逐轮强化。

六类普通敌人：追迹者、快袭者、重甲者、射手、断线者、脉冲雷；精英具有大范围预警和强抗性。断线者能烧损旧线段，迫使玩家改变织线策略。资源节点给予补能、恢复或升级资料。

24 个局内剪辑协议，按四个流派设计：几何（边缘厚度 / 大面积 / 接缝斩 / 双回路）、夺弹（容量 / 反射 / 多次返还 / 过载充能）、回声（重放倍率 / 诱饵 / 二次重放 / 冻结）、机动续航（闪避 / 倒带 / 生命 / 线能 / 拾取）。六个高阶协议按前置条件解锁，改变规则而非单纯加数值。升级暂停三选一，有限刷新；每次必有一个与当前构筑相关的选项。至少四种不同构筑可完成普通难度。

波间补给：免费恢复一次；买治疗、协议、线能、刷新。第 2、5、7 波另有随机事件三选一（例如承受未来两波敌人加速以换取高级协议，或透支生命换回声增强）；利弊真实进入状态和后续数值。

## 四、完整产品流程

大厅选择角色、地图、难度、无尽、教程、研究与玩法说明、永久强化、成就、统计、设置、返回工具页。新手独立可重玩训练关依次教移动挂线、闭环、捕弹、回声、闪避和倒带；训练不污染正式存档或付费资源。

局外五类永久强化、八项成就、角色记录 / 地图记录、按种子可复现开局。独立 localStorage 键，正式战斗每五秒和升级 / 波间 / 暂停存档，页面隐藏自动暂停，候选和事件选择保留，结算按行动 ID 去重。存储不可用时仍可游玩并提示。

手机：二维摇杆，六动作按钮，暂停、构筑、自动收线、音效、全屏；安全区、横竖屏、多指、画质、震动、伤害数字。电脑：WASD / 方向键移动，J 或空格收线，K / Shift 闪避，U 回声，L 倒带，I 超载，H 治疗，Esc/P 暂停。各按钮显示资源或冷却，不提供无效的枪械普攻按钮。

## 五、验收

制作独立入口并接入工具页；策划在实现之前保存。验证真实几何判定、边缘距离、挂线与清算区分、收线消耗 / 回复、捕弹截获和返还、回声坐标不漂移、倒带安全、线烧损、首领二阶段和预警。验证升级前置与流派差异、随机事件利弊、胜负结算、无尽、教程、暂停 / 存档恢复 / 去重、多指与横竖屏。使用真实引擎做可复现全局模拟，不能用注入无敌 / 无限生命证明可通关。浏览器实操检查流程与美术。记录实机验证边界，不用窄测试支持未验证的广泛承诺。
