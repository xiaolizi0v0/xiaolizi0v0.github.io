# 《死神VS火影 HD：重制版》游戏设计与策划规格书

## 1. 游戏概述与立项背景

### 1.1 项目定义
《死神VS火影 HD：重制版》（Bleach vs Naruto HD Rebirth）是一款基于经典开源 Flash 格斗游戏《死神VS火影》（5DPLAY Game Studio 剑jian 原创制作）架构深度复刻的高清 2D 动作格斗游戏。项目旨在保留原版经典硬核格斗手感（招式打断、受击硬直、连招保护、瞬步脱离、替身术脱离、能量觉醒、奥义特写）的同时，通过现代 Web 技术（Canvas 2D 亚像素矢量渲染）与深度学习超分辨率重构，彻底解决原版低清像素模糊、无法在现代移动端浏览器运行的问题。

### 1.2 核心体验目标
- **原汁原味的经典打击感**: 传承 5DPLAY 官方 AS3 源码中的核心格斗数值模型（`net.play5d.game.bvn`），包括 1000 点基准生命值、300 点气量上限、命中顿帧（Hitstop）、受击硬直（Hitstun）与受击浮空重力。
- **超清视觉重构**: 引入 4K 级手绘与超分视差背景舞台，搭配角色超杀 Cut-in 高清动态特写，以及原版像素 vs AI 超清重制的一键对比模式。
- **原生手机触屏优化**: 专为手机竖屏/横屏自适应打造的虚拟多向摇杆 + 弧形战斗动作轮盘（J/K/U/I/O/W/S/L/援助），支持双击快速冲刺、多点触控与触觉振动反馈（Haptic Vibration）。
- **纯离线运行与零外部死链**: 采用 Web Audio API 程序化零延迟音效合成引擎，无需依赖外部容易失效的 mp3 音效外链，随时随地秒级加载。

## 3. 经典援助伙伴机制 (Assists)

按援助键（快捷键 W / 屏幕 ASSIST 按钮）召唤援护角色入场（冷却时间 15 秒）：

2. **井上织姬（Orihime）**:
   - 技能: 孤天斩盾·三天结盾
   - 效果: 召唤椿鬼与舜樱，为己方瞬间恢复 180 点生命值并展开 1.5 秒防护罩。
3. **油女志乃（Shino）**:
   - 技能: 寄坏虫·秘术侵蚀
   - 效果: 驱使虫群吸取对手 40 点能量，并将能量回馈给召唤者，限制对手奥义。
4. **宇智波鼬（Itachi）**:
   - 技能: 乌鸦幻术·天照黑炎
   - 效果: 化为漫天乌鸦分散对手注意力，并在对手脚下燃起不可扑灭的黑炎，造成 80 点真实伤害与硬直。

## 4. 战斗物理与判定系统

### 4.1 AABB 判定盒体系
- **Hurtbox（受击盒）**: 绑定在角色躯干与四肢，每帧随角色当前姿态与动作更新。
- **Hitbox（攻击盒）**: 仅在攻击判定的有效生效帧（Active Frames）被激活。
- **Pushbox（推挤盒）**: 用于双方角色实体碰撞阻挡，防止角色穿透重叠。

### 4.2 核心防无限连机制 (Damage Scaling & Invincibility)
- **连击衰减 (Damage Scaling)**:
  - 连击数 Combo ≤ 2: 伤害 100%
  - Combo = 3: 伤害 85%
  - Combo = 4: 伤害 70%
  - Combo ≥ 5: 伤害递减至最低 40%
- **倒地保护 (Knockdown Invincibility)**:
  - 角色受击浮空落地或承受击倒打击时，进入 Knockdown 状态，获得 30 帧绝对无敌保护，起身前无法被再次追击。
- **替身术脱离 (Substitution / Kawarimi)**:
  - 在受击僵直（Hitstun）状态下，若当前能量 ≥ 80，玩家可点击替身术键，消耗 80 能量化为一阵白烟瞬间瞬移到对手背后 70px 处，实现极限脱离与反打。

## 5. 手机端触控人机工程学

### 5.1 虚拟摇杆设计
- **动态中心锁定**: 左半屏配置直径 140px 的全触感摇杆底盘与 60px 操控杆。
- **八向摇杆与死区控制**: 设置 12px 移动死区避免误触；摇杆上推即判定跳跃，双向疾推触发疾跑。

### 5.2 弧形战斗动作轮盘
- 针对右手拇指划动弧线排列按钮：
  - **J**: 基础普攻（占据右下黄金拇指落点，尺寸放大）。
  - **K**: 跳跃键。
  - **U**: 技能/远攻。
  - **I**: 必杀/突进。
  - **O**: 觉醒/终极奥义。
  - **L**: 瞬步冲刺 / 替身术脱离。
  - **W**: 援助伙伴召唤。
- **触觉振动 (Haptic Vibration)**:
  - 普通命中: 12ms 轻微振动。
  - 奥义释放与被击飞: 45ms 强烈震感。

## 6. 音效与画质模式切换

- **Web Audio 纯合成音效**:
  - 刀剑碰撞: 带衰减的高频正弦波与白噪声混合。
  - 拳击肉搏: 低通滤波三角波瞬态冲击。
  - 飞行道具 (月牙/螺旋丸/千鸟): 动态扫频振荡器产生充能与呼啸声。
- **画质切换系统**:
  - 提供 `AI超分重制 (4K HD)` 与 `原版像素怀旧 (Retro Pixel)` 实时无缝切换开关。
  - 重制版开启亚像素抗锯齿、泛光滤镜、手绘 4K 舞台；怀旧版开启像素点阵锁定与粗糙马赛克渲染，满足不同玩家审美。
