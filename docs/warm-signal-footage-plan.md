# 拍摄副本策划与验收

2026-10-10，film-4。将旧版每人三个直接扣资源的按钮，扩展为角色选择、章节地图、剧情、准备拍摄、结算、重拍与碎片合成的完整流程。男性制作人沈屿与六位成年女性合作制作日常影像；人物和故事原创。

本项目确定为六人各六章、每章开场故事＋五场拍摄＋收镜故事，共252节点（180拍摄、72短篇阅读）。36章分别有原创题材与困境；每段阅读六句，采用人物回应和共同推进句式，不能宣传为252篇独立长篇故事。章节题材见 `footage-content.js`。

以下门槛、评分曲线、掉落概率、奖励、重置价格、每日5点、补给价格均为本地游戏适配，未验证为原作当前精确配置。完整历史活动库、专业配音和原作全部运营内容仍未覆盖。

## 流程与数值

新档主线完成节点门槛依次12、18、36、54、72、12；进入角色路线后按节点顺序推进。每章五场成功后才能读收镜，读完开放下一章。已开放的故事可免费重读，首次选择保留；未读完的段落和选择位置刷新恢复。

拍摄先选择两次特殊事件的专家，再召唤至多三张该女生的已拥有羁绊，支持属性筛选和推荐。使用现有公司/专家与主副属性评分，保留SP当前阶段卡面。目标为520＋章节索引×420＋拍摄索引×100；二星1.15倍、三星1.5倍目标。该副本暂不触发升华的随机拍摄技能。

每次消耗胶片1、体力8。成功获得金币500＋章节索引×100、心愿1、制作人基础经验25、上阵卡各20经验；现有特权加成照常参与。每场首次成功20钻石，每段故事首次完成10钻石、2好感。失败消耗资源，不占成功次数、不掉落、不推进。三星不是重拍的必要条件，二星即可。

前五章每关分别独立判定R碎片40%、SR碎片25%；第六章为SSR20%、ER35%。课程卡独立30%，每项命中得到1个，可能全部未掉落。具体卡ID按角色与章节配置，后期SSR/ER是保留原项目稀有碎片来源的扩展。合成沿用既有R15/SR30/高稀有60片，已拥有时增加重复张数与星尘，不能混称为原作合成表。

章节累计5/10/15星各领一次：钻石20/40/60、金币1000/2000/3000、心愿1/2/3。故事回顾与重拍不会再次发放首次奖励。

## 日限、补给与批量重拍

上海时间每日5点重置每关3次成功额度、次数重置计数和胶片补给计数。日期只向前推进，时钟回退不能再拍摄或购买；跨日旧准备失效，需重新准备。

每关耗尽后花30游戏钻石恢复3次，每关每日最多10次重置。胶片自然每小时恢复1、上限10；新增补给每次10张、每日最多10次，价格依次30/50/100/100/200/200/500/500/500/500游戏钻石。补给可以超过自然上限，降至10以下才自然恢复。既有商城的胶片小包继续独立存在。这些均为虚拟资源支出。

单关支持重拍1次或当前剩余次数。批量面板可跨角色选已二星关卡，按当前剩余次数合并结算；先核对全部资源、额度、记录阵容和确认序号，任一无效则全部拒绝，不先扣部分资源或消耗随机数。批量使用该关保存的最佳阵容，逐次产生真实随机掉落与卡经验。最近30笔保留关卡、次数、星级、基础奖励、碎片和课程卡；首次钻石另在当次结果显示。

## UI与存档

暖米色、灰粉按钮、金色星级；角色条幅横向滑动，章节使用竖排文字签，地图在顶栏与底部动作间独立滚动。故事头部等比上对齐裁切，选择按钮固定在底部；编队仅显示目标女生，SP阶段B和普通卡面保持正确比例。

新模块独立存储六条路线、星级、最佳阵容、故事书签/首次选择、星级箱、日期额度、补给、会话序号和记录。旧档迁移保留所有资源、羁绊、主线、手机、AI设置；原副本六人入口保留开放，但不会凭空补入新章节星级或通关。原每日三关的使用量迁移到第一章前三场拍摄，防止同日重新获取次数。旧直接结算接口拒绝操作，必须经过新准备流程。
