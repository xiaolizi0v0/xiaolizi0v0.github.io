## 内容与节奏

六人各三场，共18场、72节。每节有独立开场和角色对白，第二节有两种回应及不同反馈。四节读完解锁她的日记；首次完成第二节的回应永久记录，重温可尝试另一回应，不覆盖首次记录。六人题材分别围绕植物、建筑、音乐、新闻、烘焙和镜头之外的生活。

新增原创六场景图集：温室、钟楼、天台、书店、烘焙店、直播工作室，配合已有静态立绘。同一女生共用其场景和日常立绘，通过时间色调区分约会，不宣称18套独立CG。人物等比显示，阅读切行不再重复入场淡入。

## 规则与项目数值

| 项目 | 当前实现 |
| --- | --- |
| 第一场条件 | 好感0，拥有对应角色基础R |
| 第二场条件 | 好感25，指定两张SR任意一张 |
| 第三场条件 | 好感50，指定两张SSR任意一张 |
| 四节价格 | 第1节免费，第2/3/4节分别2/3/4诺言 |
| 顺序 | 读完前节才能解锁后节；解锁永久保留 |
| 首次完成整场 | 钻石60、心愿3、好感8或6，按首次回应决定 |
| 重读 | 免费、不消耗体力、不重复奖励 |
| 初始/旧档诺言 | 一次建立12个，刷新不重复赠送 |
| 诺言来源 | 升星前星级1～5对应1～5个；每日许愿/培养任务各1个 |
| 钻石兑换 | 10钻兑1个、50钻兑5个，商城补给页亦可兑换 |

好感为本项目原始数值，区别于原作等级。指定卡牌、价格、初始赠送及奖励均为项目适配，尚无证据证明与原作逐项相同。诺言加入原有每日任务奖励，不对已领取的旧任务追补；次日刷新后可按新规则领取。

## 页面与存档

选择对象 → 三场列表 → 卡牌/好感条件与四节目录 → 全屏阅读 → 日记。缺少条件时提供许愿树/漫步入口，指定卡可看独立卡面。阅读页支持自动、三档字号、本节回顾、跳过已读；出现选择暂停自动，未读不能跳过。短屏允许对白区内部滚动。

一个进行中书签记录场次、章节、行号和本次回应，刷新从同一行恢复。退出保留书签；切换需继续旧章节或明确结束本节。结束仅清除当前行号，解锁及已读进度保留。不是每场各自保存一个进行中书签。

旧版已完成短约会迁移为四节已读，保留首次选择与资源，不重复奖励；公司/宠物约会仍在各自系统。存档校验章节、选择、完成表、单调会话号及数值边界，旧按钮不能绕过四节流程。仍属于可导出编辑的单机存档。
