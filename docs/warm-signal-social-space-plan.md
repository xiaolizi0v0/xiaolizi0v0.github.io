## 玩家流程

首页「我的好友」→「我的空间」，或制作人资料「在线个人空间」、DIY编辑器「好友展示」。编辑40字签名、最多四张不同的已拥有羁绊、访问范围和DIY优先开关；保存草稿只保存本机，点击发布才更新服务器作品。

DIY来自编辑器已保存的展示，未保存的移动、裁切和新素材不会提前同步。发布时固定相册及DIY内SP的阶段与A/B卡面，好友看到发布者的皮肤，使用等比裁切。四属性实力为发布时实际编队与公司属性之和，之后培养不会自动改变在线数值。

好友头像→制作人名片→「查看个人空间」。卡片可放大欣赏，不会获得卡牌、SP阶段、资源或奖励。撤回需要页面确认，在线作品撤下，本地DIY、签名、相册保留，可重新发布。

## 数据与服务

本地新增 `socialSpace`：版本、签名、相册ID、DIY开关、范围。旧档默认前四张已拥有羁绊、仅好友可见，不自动发布，保留原钱包、章节、卡牌与DIY。

发布载荷仅包含签名、四张相册ID、四属性、规范化DIY、涉及卡牌的SP显示阶段/变体；不上传完整存档、AI地址/密钥、聊天、订单、钱包或宠物，不接受HTML、任意URL、CSS或图片上传。

沿用Python/SQLite好友服务，数据库在静态网站目录外，新增 `showcases` 表。

| 接口 | 行为 |
| --- | --- |
| POST `/space` | 认证后按目标ID读取，每次检查当前好友关系与范围 |
| POST `/space-publish` | 仅认证身份可写自己的作品，携带期望版本 |
| POST `/space-withdraw` | 撤回自己的作品并递增版本，保留版本墓碑 |
| GET `/state` | 返回自己作品版本/范围/发布状态，不附他人作品 |

同服可见也需要服务身份。仅好友可见在解除关系后禁止再次读取；已浏览画面和截图不能远程撤销。闭合空间返回空作品，不向访客泄露签名、相册、排版或版本。旧页面以过期版本更新/撤回返回409，并发修改仅一方成功。

两端严格校验字段、数量、ID、有限数值、图层唯一、裁切、卡面与签名；最多5相框/5光影/30装饰的正常载荷低于16KB。服务只验证结构与关系，羁绊拥有、培养、实力来自本地客户端报告，并非权威资产账本。
