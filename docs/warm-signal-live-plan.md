# 心动来信 · 唐梨直播玩法策划

日期：2026-10-09。对应入口：城市主页「心动直播」。游戏直播为单机模拟，观众、弹幕、榜单和 PK 对手都由本地规则生成；不调用摄像头，不对抖音推流，不发生真实打赏。

## 角色与叙事

唐梨，24 岁，生活摄影主播，外向但不善于求助，喜欢记录晴川市的小事。男主沈屿受邀担任她的节目制作人。她的成长线从“怕冷场的新主播”走向“愿意在镜头前讲自己的故事”；亲密线从公开场合的默契，延伸到下播后只对男主说的心事。

新增角色贯穿羁绊（12 张）、许愿、养成、短信、朋友圈、来电、漫步、约会、公司合作、拍摄副本与个人空间。首批美术包含独立原创直播立绘。

## 玩法循环

1. 开播准备：选择「街区日常 / 摄影课堂 / 温柔夜话」题材、上阵 1～3 张羁绊。制作能力影响初始观众。
2. 一场 60 秒，消耗 10 体力，每日最多 3 场。三次导播事件分别在第 12 / 28 / 44 秒出现。
3. 从两项方案中选择：回应观众真实问题/照本宣科，调整镜头/继续晃动，坦诚聊天/强行推销。选择改变留存、热度及信任。每个事件只能提交一次；超时 8 秒按保守默认方案处理。
4. 点赞最多每场 100 次；文字评论最多 5 条且间隔至少 6 秒；礼物每场最多 3 次，每次 100 游戏金币；模拟邀请每场 1 次。这些互动提升热度，但不能取代导播决策。
5. 结束结算：根据留存、热度和制作能力发放游戏金币、粉丝增长、心愿和好感。收益仅在点击领取时发放一次；退出/刷新/重新进入保留原场，不重复扣体力。
6. 粉丝达到 200 后解锁模拟 PK 场，增加对手进度条和胜负奖励。PK 同样为 60 秒、同样消耗当日场次。

## 数值

- 初始粉丝 120；基础在线 35 + 上阵总分 / 25（上限 500）。
- 留存初始 65%，上限 100%，下限 20%。优秀选择 +12、保守/不合适选择 −8。
- 热度 = 初始制作品质 + 点赞 + 评论 × 15 + 礼物 × 35 + 导播选择收益。
- 金币结算 = 600 + 热度 × 2 + 留存 × 10，PK 胜利额外 600。
- 新增粉丝 = 8 + floor(热度 / 20) + floor(留存 / 10)。
- 好感 = 3 + 三次优秀选择数；心愿 = 2。粉丝、每场回放概要、最佳热度保存在存档里。

## 成长与反馈

直播页可看粉丝、最高热度、历史场次、题材和结算回顾。每 500 粉丝提升主播等级展示。剧情解锁继续使用角色好感系统，避免为同一个关系建立不互通的数值。点赞有漂浮心形；礼物有通知条；弹幕定时滚动；主播在导播事件和选择后给出文字反馈。

## 必须验证

资源不足不启动；重复点击不开第二场；离开再返回同一场；刷新恢复事件与倒计时；同事件不可重复提交；到时自动结束；结算只领取一次；当日场次刷新；PK 在粉丝不足时不能开启；评论 HTML 按文字显示；被隐藏的页面不继续播放音效；手机键盘/窄屏下评论和控制入口可使用。
