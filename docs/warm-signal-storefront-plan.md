## 参考及版本选择

原作规则并非所有年份相同。实际阅读[官方作者2017年特权卡介绍](https://www.taptap.cn/moment/15224689148297541)，确认30元、开通300钻、每天30钻共30天、续购叠加时长、签到双倍、经验加成、漫步自动及三档特权礼包结构。

[2019年升级记录](https://shouyou.3dmgame.com/gl/160102.html)为转载官方微博的次级资料，说明体力上限由+20升为+50、每周三档钻石礼包与周一心意礼包。[官方App Store历史版本](https://apps.apple.com/cn/app/id1258524226)的2024记录又将特权卡补领体力调整为免费。因此当前采用+50上限和免费补领，不混用旧版+20或1钻补领规则。

[2017年礼包攻略](https://www.9game.cn/news/2148033.html)支持1元礼包的10钻/60体力/3心愿；[早期经济攻略](https://www.9game.cn/news/2082199.html)提到68元基金及三档礼包。完整基金2.0逐档奖励表尚未取得可核对的官方资料。本项目的六章、680即时钻与后续3400钻是适配现有原创六章的演示方案，不能将它称为原作基金表已完整还原。三元与六元礼包也适配现有资源，原作约会诺言等未建立同等资源体系。

生日商城的[参考文章](https://www.qieyou.com/content/151314)可定位图片，但原图请求超时；本轮未据此声称精确复刻商城图片。界面沿用本项目奶油底、豆沙玫瑰按钮、浅杏金边，以四个顶部页签组织商城。渠道付款页随平台变化；统一采用用户指定的任意4位数字本地模拟流程。

## 页面和支付

「推荐 / 特权卡 / 影视基金 / 资源」四页共用余额、返回城市及钻石充值入口。推荐展示两张常驻权益卡、每日体力和每日礼包。特权卡页包含有效期、续购、今日领取、实际权益及周礼包；基金页显示六章条件、可领取/已领取/前往主线；资源页保留原有五种兑换与六人星尘羁绊兑换。

特权卡、基金和三档礼包使用已有「确认商品和支付方式 → 任意4位数字 → 成功回执」流程，计入累计模拟充值，首次购买不翻倍。钻石充值页仍仅显示原有六档独立首充双倍。支付面板、回执及最近50笔历史显示商品名称和全部资源；旧订单和领取记录保留。商城及充值页均可继续/取消未完成订单。

数字仅存在本次界面内存，关闭、返回和成功时清空；不进入存档、订单、日志或网络请求。全部模拟金额不产生真实扣款。

## 基金和礼包

基金模拟68元，一次开通即时680钻；完成每章全部18节点后，依次手动领取300/400/500/600/700/900钻，合计4080钻。购买前已经完成的章节可补领；每档一次，不依赖每日或特权有效期。

每日礼包需有效特权，每档每天一次，上海5点恢复：

| 模拟价格 | 奖励 |
| --- | --- |
| 1元 | 10钻、60体力、3心愿 |
| 3元 | 30钻、10000金币、5心愿 |
| 6元 | 60钻、1许愿券、6心愿 |

每周礼包需有效特权，周一5点恢复。当前三档常驻组合为30钻兑100体力/3心愿、100钻兑20000金币/10心愿、300钻兑3许愿券/10星尘；周一另有1钻兑60体力/3心愿。以上周礼包价格与资源组合为项目适配，不代表原作精确表。

## 事务和存档

新增`storefront`保存特权起止日/最后领取日、基金购买/章节领取、每日礼包/体力与周礼包限额。充值记录升为v2扩展11种商品；v1六档订单自动迁移，保留待支付阶段、方式和全部历史，不改变已有资源。额外权益不会被当成钻石档位首充。

付款再次检查权益和资格；每日礼包的待支付订单跨5点后必须取消重新选择，不能用旧额度付款。体力补领确认再次核对日期及费用；周兑换确认核对周次。发奖前校验资源上限，失败不扣费、不占额度。重复支付、重复领取和失效订单号被拒绝。时间回退不会重新激活已过期权益或重新发放每日钻石。

本地存档可以由玩家编辑，结构校验只防止错误导入和常见不一致，不提供真实支付签名、服务器时间或账户防作弊。
