# 松风小院：森林接力玩法、剧情与内核策划 v2

2026-10-08，用户明确要求玩法创新、不复刻动物森林，也不采用FPS/肉鸽等方向。本文件在新玩法实现前确定，**取代gameplay/core v1的种植、生产、购买、交付循环**。动物森林仅提供温暖美术氛围。旧content/engine为尚未发布的初步草稿，将整体替换，不用已有代码反过来限定设计。

## 核心玩法：把一件小事托给森林

玩家像写一句短短的生活句子：选择一个开头（雨来了、收到便条、发现小东西、朋友将远行），选三位动物，每位选一种“顺手帮忙”的方式。一份心情会在三位动物间自动接力；不同动作转换心情，先后顺序会改变结果。结果是一张可永久收藏的生活片段，留在小院里。

四种心情：暖意、安静、好奇、勇气。每位动物有保留心情的动作和一种个性鲜明的转换动作，转换是不同的可逆排列，不能只用交换名称掩盖相同规则。兔子写便条、狐狸留座、小熊接过负担、水獭装收藏盒、小鹿留空隙、刺猬修补、猫头鹰借灯、浣熊换一种修法。界面逐步预览“谁接到什么→会变成什么”，无需心算；按序搭配有实际结果差异。

例：同一封暖意便条，先让栗尾留安静席位、再让溪豆装进收藏盒，与反过来的顺序会留下不同心情。既能简单选喜欢的动物、自动看故事，也能偶尔试一次顺序，发现新的回声。

## 低注意力与完整范围

- 三个接力位，8位动物每位两种动作；同条接力不能重复动物。四个开头。共有四种心情×336动物顺序×8动作组合=10752种有效配置。不是10752篇独立剧情，实际结果由下述手工内容组成。
- 每段可选15/30/60秒（同奖励、不同观看节奏），三段完成45/90/180秒。安排后无需操作，任意时刻移开视线不会失败。默认自动继续同一约定；改安排只影响下一封，正在传的便条保留原安排。
- 三份约定可存/取：看电视、雨声里、慢慢走。无材料、体力、金钱和生产器，不靠重复收取赚装修钱。可停止后续接力，当前便条仍会完成；再回来结果保持。
- 32张“动物×最终心情”片段，每张独立标题/正文；重复片段增加1页回忆，新片段增加3页。每份完成同时给参与的三位朋友各1点友谊，最高12。
- 16个顺序回声：第一位与第二位为特定相邻或隔三位伙伴，开头为指定心情时，产生额外独立小故事；首次额外2页。每个有可见提示，不依赖限时或纯随机。可预览配置是否满足已知提示。
- 每只动物在3/6/12友谊时解锁三封独立来信，共24封。达到即永久可读，不催领取、不消耗情绪。
- 24章小院故事、4个森林地点，按累计回忆页门槛1/3/5/8…180解锁，点击展开空间变化。没有付费、资源施工门槛；每章送一件新场景装饰，共24件、6摆位，永久免费换摆。
- 24章正文和8动物/24来信沿用story v1的原创情感故事，但用接力相处推进，不保留“买家具/交材料”作为主要玩法。32片段、16回声分别记录结果与特定关系链，终章之后仍可试验配置、回读和布置。
- 可切白天/傍晚/夜晚氛围，声音默认关，低动效可选。场景中动物的接力状态真实对应便条，而不是随机装饰动画。剧情随时关闭、回读，所有奖励有永久账本。

## 实现内核

纯JS模拟器，与竖版DOM分离。状态包括已配置约定、正在传递的不可变快照、下一段时间、当前心情、自动继续、累计回忆页、32收藏/16回声、8友谊、24已读来信、24章与家具、最近12条发生记录。没有随机抽奖，收藏靠玩家设计路线。

每次tick按绝对时间依次执行接力段；最多结算12小时。越过上限时将正在传递的下一段时间顺延未结算间隔，保证过长离开后仍可继续、不把已结算时间再刷一次。倒拨时不回退基线。配置变更只写下一封，完成前不替换现有快照；自动继续每次从当前约定复制一份新快照。每封完成一次后删旧快照再派下一封，防重复。

独立存档pine-haven-relay-v2。严格校验角色不重复、动作0/1、四种心情、阶段0—2、心情与阶段排列一致、绝对时间和有限计数、各集合范围、家具和章节已开启关系、正在执行快照与显示状态。导入展示进度后确认、保留最后有效备份、无效数据不替换。修改安排不扣费，所有阶段可恢复。
