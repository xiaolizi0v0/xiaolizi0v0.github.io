# 新游戏当前权威状态

2026-10-08。用户最新明确要求：“重做，还是做割草游戏吧”，并要求结合微博热搜，设计舆论玩法，提供热搜榜页面和动效。当前正式产品为《热搜清屏》，入口tools/HotSearchReaping.html，目录tools/hotsearch-reaping，策划见hotsearch-reaping-plan.md。沿用自动战斗为主、少量手动操作、解压体验、永久成长与温暖圆润美术。

- 当前广泛玩法研究见market-gameplay-map.md：59种常见玩法/细分类型、跨类型结构、代表作品、官方资料及创新判断。此前pine-haven-research-v3/v4保留为部分竞品研究，不再作为正式方向的权威决定。森林共生网络不再是正式方向。
