# 松风小院：玩法策划（开发前）

原创单人竖版动物森林生活游戏。横屏和桌面保持居中的竖版游戏框。没有输赢倒计时，短回访、长观察均有完整玩法。

## 主循环

收取自动积累的叶币和花园作物 → 给工作台安排制作 → 用食物招待动物、送永久有效的小心愿 → 取得友谊和纪念品 → 修建小院、布置家具、解锁森林地点 → 阅读动物故事。按钮一触完成，动作与资源结果有明确反馈。

## 内容范围和规则

- 4地点：松风小院、苔石溪畔、萤火林地、山顶茶亭；每处6项建设，共24项、24段独立剧情。修建只扣叶币；主线目标不索要稀缺材料。终章后所有来源继续工作，可回读全部故事。
- 8位有姓名/习性/喜欢食物的动物。每只友谊0—12，3/6/12时解锁三段来信与纪念物。招待消耗明确的一份食物、友谊+1，不设饥饿或关系下降。重复招待仍可获得叶币，最高友谊不会吞掉礼物。
- 叶币自动产出，基础每秒0.6，每项建设额外0.14；自动积累上限12小时，收取不需要逐件点。一次点按“收下小院收获”领取货币及成熟作物。首次给160叶币、少量材料和两份点心；建设费用从60到约1800渐进。升级建设带动产出，不加入买体力门槛。
- 4块花园、6种作物：莓果/小麦/茶叶/南瓜/棉花/蜂蜜。种植免费，45/75/120/180/240/300秒成熟；手动收取和已设定自动照料都保留所选作物，自动重新种植。可换种，先收成熟旧作物；未成熟换种会明确确认，不扣材料。
- 12份配方：六种轻食、四件小工艺、两件纪念料理。显示材料/时长/产出和解锁条件；3个并行工作位，材料先验证后扣，30—360秒，完成等待领取无超时。初期主线依靠花园和免费种植可持续推进。
- 3个旅行目的地，90/180/300秒，零材料入场；同一时刻一队，取得材料和20种自然发现的永久记录。重复发现转叶币，不影响主线。旅行结束等玩家收取；收集的随机序列存档，刷新不能重抽。
- 24家具，6个摆放位置；家具第一次购买后永久拥有，多次切换免费。类型涵盖木椅/灯/花盆/茶具/毯子/鸟屋等，场景中可见；8个里程碑提供家具，16个用叶币购买。允许恢复为空，不删除拥有记录。
- 每位动物固定3个常驻小心愿，共24份，交付指定配方，送叶币和友谊；一次性领取保存。无每日期限。图鉴20自然物+24纪念来信，全部可查来源。
- 花园、制作与旅行可并行。没有连击、催促通知、连续签到奖励或付费加速。回访只给一份汇总，不连弹多窗。可主动切换白天/傍晚/夜晚，纯视觉、不改变概率。

## 体验与信息架构

底部5页：小院（完整场景、收获、下一建设）；花园（种植、制作）；朋友（招待/愿望/来信）；森林（旅行和收藏）；布置（家具/设置）。资源栏不随弹窗跳动。详情底部关闭/确认按钮至少44px；单手操作无拖动依赖。可开启低动效、自然环境声，默认静音。长正文内部滚动，关闭返回之前页面；未读剧情保留标记而不阻断经营。
