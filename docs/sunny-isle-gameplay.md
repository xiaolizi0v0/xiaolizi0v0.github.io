# 晴岛夺核：玩法策划

2026-10-08。开发者依据市场研究选择并承担验证，不声称用户已认可。完整目标是竖版可玩游戏，验证模型只用于排除问题。

## 主循环

看雾兽各部件自动交战 → 决定拆解或接管以及攻击优先级 → 接管部件在敌体上反用，断开的供能路径导致停机 → 击破雾核完成交战 → 获取成长资源、修复群岛并解锁新结构 → 持久策略继续推进。

玩家不必移动、瞄准或手动出招。点部件可临时指定目标与处置，持久策略则覆盖后续交战。非FPS、非肉鸽、非五人配队，也不以建设防御塔或军团攻城作为主玩法。

## 敌体结构与真实规则

雾核是胜利目标，不能接管；其余部件有生命、归属、容量成本、能源需求与连接。能量芽产生能源，通过有方向的连接和存活中继传播。红色来源可给沿途双方部件供能；接管后的蓝色能量芽只供给蓝色部件。能源按可达消费者需求分配，不足时攻击和修复效率下降。节点被拆除会断路。

炮瓣：敌方攻击守望者，蓝方反击敌体。盾叶：敌方保护雾核，蓝方减少守望者受伤。修复苞：敌方修复受损部件，蓝方治疗守望者。甲片：保护相邻敌方部件，接管后增加守望者减伤。中继：维持路径，接管后不改变拓扑。潮铃：敌方周期覆写邻近蓝色部件，蓝方抑制敌体攻击。孢芽：敌方产生小雾团攻击，蓝方把能量转为额外反击。

雾核保留低强度独立攻击，后期有持续加压，避免停机后无限安全磨血。蓝色功能需要真实供能，不能凭颜色获得永久攻击倍率。

## 少量操作与策略

五种持久策略：断能（优先拆能源与中继）、夺炮（保留供能，接管火力）、护航（优先接管盾叶和修复苞）、破甲（拆保护部件再打核心）、均衡（根据生命、威胁与容量选择）。默认使用均衡，不要求每关重新配置。

点击战场节点打开信息卡，显示功能、归属、生命、供能、容量以及上下游。点击拆解/接管设置当前目标，取消后恢复自动策略；释放蓝色部件会拆除并释放容量，需要明确按钮动作，不能误触空白触发。策略可存为三个命名预设。所有处置都在战斗内真实执行，并有事件记录解释停机和接管失败。

## 内容与进度

六座岛，48关固定战役，每岛八关并包含一种区域首领；八类基础结构、不同功能分支和岛屿规则形成组合。不是随机刷三选一。前八关逐步展示接管、断路、修复、容量与首领覆写。

三名可切换守望者，有不同普攻与基础生存取舍；12项永久研究，八种可购买并装备的战斗器具，两个装备槽（后期第三槽），16项成就。六项独立结构试炼，使用固定等级规则比较策略，不能通过永久等级碾压。主线通关后可回访训练、完成试炼和策略优化。

自动推进可开关；失败后回到最近已过关训练，并定期尝试当前前线。训练与掉落来自真实交战，重复失败不会清空永久资源。暂停明确暂停，后台/离线补算最多24小时的实际交战；超过时长明示。倍率与策略在在线和离线一致。

## 竖版页面与功能

战斗首页：地区/进度、双方生命、容量、可点击敌体、策略、自动推进、暂停、倍率、音效、震动与低动态设置。下方导航：战斗、群岛、工坊、图鉴、手册；手机触控目标最小44像素，考虑刘海和底部安全区。

群岛：章节地图、关卡规则、解锁状态、回访、独立试炼与章节剧情。工坊：成长研究、守望者与装备选择。图鉴：敌体功能、接管结果、上下游与已发现节点、成就和统计。手册：分步教学、机制图解、策略保存、存档导入导出与新旅程确认。

战斗展示具有投射物、命中冲击、部件碎裂、共鸣变色、能量流和战后平静反馈；音频由浏览器首次交互启动，可静音。优先可读性，低动态模式减少闪光和镜头震动。不能用一张静态图和数字按钮代替战斗。
