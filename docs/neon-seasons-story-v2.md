# 剧情策划 v2：老屋与四季站

保持原创六人关系、00:04录音谜团、四季的64项剧情、8条记忆物证和三个结局，新增进入幻想岛前的现实老屋段。真实时间通过生活修复向前走，幻想站保存未被完整理解的过去；老屋与岛可以随时往返，不能把故事简化为施工按钮。

## 老屋八场

|场|装修与场景变化|剧情推进|
|---|---|---|
|0 清理旧地板|纸箱、蛛网移开，木地板显露|乔宁回到白禾留下的住处，陆岑带来工具箱。介绍“交单取得金币，先恢复住处”。|
|1 打开朝东的窗|修窗、窗帘及晨光|白禾说先让屋里有风。窗台发现重复写着明天见的预约便条。|
|2 修复旧沙发|沙发从破旧变布艺，软垫落位|朋友各留一个位置，陆岑无需先被原谅才能坐下。|
|3 重开小厨房|灶台、杯柜、暖灯|首次工作餐，恢复体力。白禾的配方仍按人数写。|
|4 整理窗边花台|植物、生长架|池远带来花箱；自动产出成为可操作教程。发现没有名字的种子。|
|5 铺好六人的桌|餐桌、椅子、餐具|闻溪带来雨声录音，乔宁认出纸上倒写日期。|
|6 修好阁楼书架|梯子、书架、台灯|阿灯醒来，说明没有未来录音，只有尚未播放的声音。|
|7 推开四季的门|霓虹门、完整住处|幻想岛出现，当前六人与彼时的六人连接。升级与剧情共同开放岛屿；给下一件生产器零件箱。|

每场至少两条独立角色对话并有装修前后图像变化，8场可回看。原有64场逐条保留独立叙事文本，但将“提交施工材料”的台词改为订单经营所得带动修复，不引入建造星。

## 四季与支线

春篇16场：重开站、温室、咖啡屋、电台，认识自己的失约；夏篇16场：潮汐、演出、泳池、工坊，发现停电是在救人；秋篇16场：印刷、厨房、记忆展、换乘，拼回被剪辑的证言；冬篇16场：钟楼、暖屋、观测、灯塔，决定记忆与明天的关系。

支线的故事随物品的实际演化发生：工具和针线留下线绳，成为童年玩具；花瓣变香水，等待后留下玻璃，成为礼物盒。八个原有信物分别补充角色视角，不以同一段文案重复占位。信任达到3/6/10有一次性对话和物品/装饰奖励；全记忆相册解锁外婆的信。

结局保持三种：归还完整时间、留下公共记忆馆、画新一年站台。首通资源奖只领一次，结局可重读选择，选择不会删除装修或物品。终局继续大师订单与长期活动。

## 视觉方向

用户要求的霓虹青绿、青蓝、淡紫和橘暖色继续用于UI；室内灯光温暖，幻想岛植被与水面带轻微光晕。新场景、角色、道具采用原创绘制，不直接套用官方角色、截图、纹理或剧情。地图需要完整构图与局部装修变化，人物对话保留独立肖像和清晰阅读空间。
