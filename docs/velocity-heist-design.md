# 劫速街区 / VELOCITY HEIST

策划先于实现保存：2026-10-01。目标是独立完整的手机端赛车肉鸽，沿用深灰、荧光绿、紫青、斜切与潮流动漫美术，不做横版，不覆盖之前两款游戏。

用户追加要求：赛车模型用 Blender 制作，游戏改为真正 3D。最终方案采用本地 Three.js / WebGL2 渲染真实三维车模、赛道、建筑、灯光和追车透视镜头，加载 Blender 导出的 GLB。保留可编辑 `.blend`、建模脚本、三款不同结构车型。平面封闭赛道的驾驶规则保持连续纵向速度与横向惯性；世界呈现为三维，支持较高视角的固定方向镜头。以下原俯视 2D 美术描述由此 3D 要求覆盖，赛事、构筑、养成与验证要求保持完整。

## 研究与差异

官方资料：
- [Driving Rogue](https://store.steampowered.com/app/3088700/Driving_Rogue/)：漂移、交通缝隙、擦车连击、升级与特殊能力，动态城市。
- [Reality Drift](https://store.steampowered.com/app/3078120/Reality_Drift/)：赛道选择、卡牌与遗物、速度 / 加速 / 抓地构筑，官方描述电脑车辆也参与竞速。研究时为尚未正式发行的作品，不把宣传当作实测结论。
- [Death Roads 官方](https://theknightsofu.com/projects/death-roads-tournament-all-stars/)：回合制卡牌车辆战斗、换挡与攻防。

推导：本作以实时竞速、名次、弯道控制和可争夺路面为核心。创新组合是「尾流连接 → 交换车速 → 漂移蓄能 → 共享加速轨」，不宣称全球首创，不把赛车换皮为自动射击割草。

## 主要玩法

地图扩展：用户要求尽可能多的地图，最终提供 24 张有独立控制点布局的封闭赛道，每类街区 8 张。大厅有全部地图的路线预览、风格筛选与首站选择；赛事优先轮换未使用地图，前 24 站可覆盖整个图鉴。每张地图进一步支持极速、技术、安全三种路线调整和种子扰动。弯角自动圆滑，限制曲率与路宽的乘积以避免内侧路边折叠。

| 街区 | 8 张地图 |
| --- | --- |
| 高架断层 | 天际外环、断层双切、三角天桥、菱形高塔、云端回钩、阶梯匝道、风口斜坡、悬空回折 |
| 磁轨港口 | 集装箱方阵、港湾水道、起重机回钩、双码头连弯、龙门长廊、货运蛇湾、船坞大碗、水闸折返 |
| 雨夜环城 | 雨幕环城、霓虹大道、月牙湿地、旧城棋盘、电光折线、公园三叶、夜桥斜环、暴雨回港 |

俯视闭合赛道，有真实累计进度、起终点、圈数、赛道雷达和 AI 排名。使用沿赛道距离 + 横向偏移的街机驾驶模型，具备加速、刹车、横向惯性、弯道离心偏移、漂移、撞车与撞墙损耗。默认自动油门并沿道路方向辅助，玩家控制车道和漂移；可关闭自动油门。没有位置交换或隐藏名次修正。

跟入前车尾流：前车在前方 20–230 距离，横向距离足够小，持续跟车建立连接。拉出尾流后连接短暂保留，可按「换速」交换双方当时的纵向速度，自己的较低车速交给对手。各车位置和比赛进度完全不变；冷却、防止重复取速、连接丢失可读。

漂移与跟车蓄电。按「铺轨」在前方当前车道放一段持续存在的加速路轨；所有参赛车都能使用，领先时需要决定是否送给追赶者。每车每圈同一轨只触发一次；轨有长度、宽度、寿命、使用统计。后续构筑能延长、扩大、增益自己或从对手使用轨道赚取资源。

主动操作：转向摇杆、刹车（按住）、漂移（按住）、换速、铺轨、氮气喷射、护盾、有限维修。撞车会掉速、损耗车体并断连，漂移和喷射产生热量，高热有明确惩罚，冷却与维修可构筑。

## 内容与进程

三辆开局可选车：穿针（尾流连接更快）、铁壳（耐久与碰撞保护）、侧风（漂移收益与抓地）。三城市：高架断层、磁轨港口、雨夜环城。种子生成闭合曲线、障碍、维修 / 电池 / 资料 / 货币节点和 AI 风格。

完整行动六站，每站两圈，最终站三圈；7 车竞赛，前五站前三晋级，最终需要前二且领先首领。第 2 / 4 / 6 站有三种首领车，分别换道封锁、铺设共享磁轨、高速收费区；首领靠超车与完赛击败。首领技能有可见提前预警。AI 包含抢线者、短冲者、漂移者、重车，正常跟车、变道、用共享轨；车速与位置连续推进。无尽持续站次、递增强度，允许主动结算。

局内 24 个改件，18 个基础与六个有真实前置的高阶，四组：尾流换速、路轨控制、漂移热管理、赛车续航。资料升级暂停三选一，有限刷新、相关选项保证。四种构筑需要以正常规则完成普通六站，不能注入无敌或满级验证。

每站完赛给予成绩、维修币与至少一次改件选择，进入车库买维修、维修针、改件、电池、冷却。之后三条路线选择：极速捷径（更短、更窄、风险高、额外币）、技术路线（更弯、漂移收益与改件）、安全维修线（宽路、恢复、低回报）。路线真实改变下站赛道和回报。第 2 / 4 站还有利益与代价同时生效的异常合约。

局外五类永久研发、八项可领取成就、车手 / 城市记录、最佳单圈与累计漂移 / 超车 / 换速 / 路轨使用统计；独立种子设置、本地养成与战斗断点、每五秒及流程转换保存、候选和路线保留、结算 ID 去重。隐藏自动暂停，存储禁用时退回内存。

独立六步训练：转向、漂移、尾流、换速、铺轨并驶过、喷射。训练保证安全且不覆盖正式断点、不给正式资源，随时可退出重玩。

## 界面与制作

独立工具入口 id 9：`tools/VelocityHeist.html`。原创海报与三车选型，实时赛道由 Canvas 绘制：俯视车体、滚动场景、轮胎印、尾流粒子、连接指示、路轨光效、烟火与震动。HUD 展示名次、圈数、路程、速度、车体、电量、热量、尾流对象与换速收益、地图与排行榜。比赛音效 / 节拍 / 引擎声使用 WebAudio。

横竖屏、安全区、多指 pointerId；二维摇杆只负责相对车身左右转向，上下可控制油门 / 刹车，独立漂移与刹车按键。手机按钮和键盘对应：A/D 或左右转向，W 油门，S 刹车，Shift 漂移，J 换速，K 铺轨，空格喷射，U 护盾，H 维修，P/Esc 暂停。包含构筑、设置、音效、全屏、自动油门、导航辅助强度和低画质；局内菜单真实停止比赛。

## 验收要求

验证赛道取样与长度、连续圈数和名次、完赛时间插值、尾流前后与横向条件、换速不换位置、连接冷却与失效、路轨所有车共享且每车每圈仅触发一次、漂移电量与热惩罚、车体损坏与有限维修、真实 AI 推进 / 变道 / 首领预警。验证改件前置、路线与事件的实际数值、六站晋级 / 最终首领要求 / 无尽、教程和存档去重。

用规则引擎跑至少四种正常构筑完整普通行动，浏览器实操教程、续玩和结算，检查工具入口、实际渲染及手机横竖屏，记录实体手机性能与物理多指的未验证边界。策划、实现、测试、海报提示词与截图全部保存在工作区，未授权不发布远端。
