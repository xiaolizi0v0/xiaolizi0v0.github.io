# 独立羁绊卡面与皮肤修正

2026-10-09，用户反馈：卡片图片拉伸，同一角色不同羁绊却显示相同图，SP 应有不同皮肤。

## 根因与实现要求

旧卡面只按角色编号取得同一幅肖像；五角色图集采用 `background-size:500% 100%`，同时适配容器宽高导致非等比缩放。角色头像仍可使用角色肖像，但羁绊卡面必须按卡牌编号映射不同图。

六位女生分别生成 4×4 图集，每格为独立服装、姿态和场景。96 张卡各占一个不同格子；原有编号 0～83 保持不变。84～89 为公司 ER，90～95 为新增 SP 皮肤羁绊。每位女生的两张 SP 使用第 9、15 格，服装与场景各自独立。

图集由 SVG viewBox 截取对应格，`preserveAspectRatio="xMidYMid slice"` 等比裁切，避免固定百分比高度拉伸，也避免裁切混入邻格。卡册、完整图鉴、拍摄阵容、抽卡结果、详情、DIY 相框和宠物联赛助力使用同一取图入口。角色资料与剧情立绘保留角色身份肖像，并修正原有等比背景缩放。

新 SP 通过星尘商店兑换，每张 120 星尘，与原 SP/UR 入口并列。重复抽中同一张卡仍会转换星尘，这是游戏的重复获取机制；不同编号的羁绊必须呈现不同卡面。

## 映射

| 图集格 | 对应编号 | 内容 |
|---|---|---|
| 0～11 | 角色编号×12 + 格编号 | 原有 R/SR/SSR/SP/UR/ER |
| 12～13 | 72 + 角色编号×2 +（格编号−12） | 两套宠物 ER |
| 14 | 84 + 角色编号 | 公司专属 ER |
| 15 | 90 + 角色编号 | 第二套独立 SP |

完整身份与服装场景提示词见 `warm-signal-card-art-prompts.md`。PNG 原件与 JPG 版保存在 `tools/warm-signal/assets/cards-*-v1.*`。公司四步项目界面现已接入，实际完成唐梨项目并获得 ER 89，详见 `warm-signal-company-plan.md` 的流程证据；其他原作活动及剧情体量仍需扩充。

## 验收要求

- 96 个卡面键不重复，每位女生两张 SP 的图集格不同。
- 文件真实存在，图集尺寸来自实际文件，每格宽高比用于浏览器等比裁切。
- 实际查看用户截图中重复的顾清禾卡面，修正后服装/姿势不同且人物比例正常。
- 详情与列表使用同一图；刷新保留原有养成和持有数量。
- 手机、桌面及 DIY 使用等比图像，无邻格混入和横向溢出。

验收结果：53 项游戏/公司逻辑/卡面测试通过；浏览器完整图鉴实际呈现 96 个独立卡面键、六个 JPG。顾清禾与唐梨 SP 比较已保存截图，旧存档持有数和养成保留。
