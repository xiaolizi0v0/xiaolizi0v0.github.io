# 裂潮：霓虹清场 — 游戏策划

## 定位与美术
手机浏览器优先的原创 2D 横版动作割草游戏，直接从博客工具页进入。参考用户截图的炭黑、酸性绿、紫红与青蓝配色、斜切框、涂鸦标题和速度线；人物和场景用原创矢量绘制，不使用截图中的商标或人物。无需账号、付费、远程接口或构建服务。

## 核心循环
选择角色 / 章节 → 横版战斗 → 击杀掉落经验、恢复物和货币 → 升级三选一 → 波次补给商店 → 精英与首领 → 结算 → 永久强化 / 角色解锁 → 更高难度或无尽。战斗倒计时只在实际战斗时推进；升级、商店、暂停不消耗时间。

## 操作与手感
左侧水平摇杆和平台下落键；右侧普攻（可按住连续出招）、二段跳、带无敌帧的闪避、专属技能、能量大招和治疗。自动攻击可切换，仍可手动操作；PC 支持 A/D 或方向键、J 普攻、K 跳跃、S 下落、L 闪避、U 技能、I 大招、H 治疗、Esc 暂停。手机支持多指同时移动与出招、全屏、横竖屏、安全区。打击包含三段连击、击退、暴击数字、顿帧、震屏、拖尾、粒子、音效和连杀评级。

## 角色
1. 零刃：初始开放；近战三连斩，回旋刃技能，超载全屏斩。
2. 火花：用通关收入解锁；穿透射击，散射弹幕，轨道轰击。
3. 霜棘：用通关收入解锁；范围法球，冻结脉冲，冰晶风暴。
所有角色均可先试玩；试玩不消耗货币，也不结算永久收益。

## 内容与难度
三章各六波：废线街区 / 电弧工厂 / 裂隙天台，分别有冲锋型、弹幕型、召唤型首领。每波有击杀配额，并需持续压制裂隙 28 / 32 / 36 / 40 / 44 / 48 秒；计时归零、配额完成且精英 / 首领清除后进入补给。含升级与补给决策的游玩时长目标约 5–9 分钟一章。第五波精英，第六波首领。小怪包含近战、快袭、坦克、远程、飞行和自爆六类，攻击预警明确；首领有二阶段。章节顺序解锁，普通 / 困难 / 极限三档；无尽六波循环且逐轮提高强度。

## 构筑
24 项局内升级，包含伤害、攻速、暴击、吸血、护盾、磁吸、经验、移速、额外弹道与六种自动武器；武器达到 4 级并取得对应被动后觉醒。升级每次三个互异选项，有有限刷新；局内背包显示等级与觉醒条件。武器分别支持环刃、雷击、烈焰、无人机、冰刺与震荡波，构筑有明确功能差异。补给购买回血、治疗次数、属性或额外升级，并提供一项免费恢复。

## 局外与存档
战利品货币用于五类有限等级永久强化及角色解锁。三个每日任务（按设备本地日期刷新）、八项成就、统计与最佳记录。localStorage 持久化角色、设置、任务、升级和战斗快照；战斗中每 5 秒存档，也在暂停、升级、波次及页面隐藏时保存。继续战斗从已保存状态恢复；结算只发奖一次。储存不可用时明确提示，并继续内存游玩。

## 手游功能按键
大厅：出战、章节、难度、英雄、强化、任务、成就、操作说明、设置、返回工具页。战斗：摇杆、普攻、跳跃、闪避、技能、大招、治疗、自动开关、暂停、背包、音频、全屏。暂停：继续、设置、背包、结束并结算。结果：再战、返回大厅。设置：音量、音效、震动、震屏、画质、伤害数字、辅助自动攻击。

## 验收
验证入口、三个角色技能、受击与无敌帧、升级刷新和觉醒、六波通关、三种首领、无尽续关、胜负结算、暂停无时间流逝、存档恢复与刷新、任务奖励防重复、键盘和多指触控、手机横竖屏布局。内容按上述范围完成，不依赖后端。浏览器运行和实际游玩验证后记录限制。
