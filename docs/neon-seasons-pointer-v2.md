# 棋盘手势可靠性策划

目标：保留拖动与点击两种操作，使手机上的中断、多指触碰和页面切换不会误消耗材料或留下悬浮物。

- 仅主指针、左键可开始棋盘手势；第二指不接管正在进行的手势。
- 正常释放时才移动或合成；系统取消、失去捕获、离开页面、窗口失焦、关闭弹窗和切换页面都取消手势。
- 取消时移除拖动物，释放捕获，清理按住状态；取消自身不调用生产、移动或合成。
- 捕获丢失后清理对应按住状态，避免计时刷新永久停住。
- Enter 和空格均可操作棋盘格，按键长按不反复生产。

验证：用真实事件处理器的独立 DOM 测试夹具覆盖主指针、第二指、拖动目标、取消和生命周期；用页面正式导出保护存档，再检查浏览器支持的真实拖动或键盘操作。夹具不等同于真机多点触控验证。

## 实际结果

`pointer-tests.cjs`七组通过，执行 app.js 中的真实注册处理器，移动/合成/交换调用真实 Game.move；DOM 与触点仍是明确的独立测试夹具。新增主指针限制，丢失捕获删除按住状态，关闭弹窗、不同弹窗打开、Esc、失焦、隐藏与 pagehide 统一取消；Enter/空格去重长按。

浏览器390×844实际使用原生拖动接口：第3格小木屑→第23格空格；第23格→第6格小木屑合成短木条2；第6格短木条→第4格螺丝钉交换；拖出棋盘到说明区域保持两格不变且无悬浮物。空格选中螺丝钉1、回车操作空格，将其移到第23格。金币229、体力461均不消耗。多点触控、系统中断只由夹具验证，未声明真机验证。
