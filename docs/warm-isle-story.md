# 暖岛矿务所：剧情策划

世界：群岛曾由一条矿材公共物流连接，运输停摆后居民各自储存了很多材料，却难以协同。玩家接管旧矿务所，把矿石送到港口，修复灯塔、桥梁、轨道和公共设施。问题是沟通与协作失序；角色不存在死亡危机和倒计时。

叙事服务产运销：现场对话解释某项新设施为什么需要，也展示运行后改变。每章约100—160字，自动保存，可跳过、重读。角色为原创工程团队，温暖圆润的视觉只是画风，不设定为动物森林的人物或世界。

|岛|四个工程/剧情节点|系统展开|情感变化|
|---|---|---|---|
|晨湾|点亮值班室、修复轨道、重开材料站、灯塔归位|产运销和岗位|从一间旧办公室看到小成果|
|潮音|码头铺板、潮汐表、缓冲仓、往返航线|周期接收、缓冲|船晚来仍有准备，不再着急|
|赤陶|栈桥加固、长线升降、分段运输、山路通车|长链运输、优先级|把各自忙碌改成互相接力|
|雪铃|避风站、储藏大厅、温室框架、共享工棚|仓储处理、储备|为别人留出余量也帮到自己|
|翠镜|修复水轮、交接试验、回流通道、协同中枢|班组支援|每个岗位有被看见的贡献|
|星港|环岛时刻表、备用航线、中央调度、群岛重连|条件调度、方案切换|玩家把一套可持续系统留给大家|

八位主管：阿洛（开采）、林宁（运输）、米夏（仓储）、陶叔（稳态采矿）、夏岚（批次搬运）、苏禾（缓冲）、杜衡（支援）、小满（综合调度）。每人通过工程里程碑解锁，能力明确、没有随机稀有度。

剧情图片采用图片生成制作原创岛屿修复场景，每岛一张主视觉作为该岛四章的共同场景；每章文字描写具体不同工程，完成阶段用场景覆盖物变化表现，不能把六张背景宣称为24张独立插图。后续若需每章独立画面按章另行生成。首轮制作六张场景，不使用竞品截图素材。

结局是公共物流恢复，而非关服或清空进度。长期玩法保留原来的设施、主管、研究与配置，新的持久委托提供下一步目标。故事不催促玩家，不让停玩影响角色安危。
