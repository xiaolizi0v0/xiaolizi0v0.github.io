# 暖岛矿务所：内核与开发策划

内核体验：发现瓶颈→尝试配置→运行自动系统→看见资源恢复流动→把收益投入下一层机制。成熟爆款主循环提供明确成长，错峰、协作、缓冲、条件调度提供决策。解压来自控制感、可逆选择和规律反馈，保持系统策略深度。

## 技术

独立入口tools/WarmIsle.html，资源目录tools/warm-isle/。不修改已有NeonSeasons和VelocityHeist存档。模块分content.js、engine.js、app.js、style.css；单机无外部游戏服务和付费依赖。主引擎确定性固定步长；浏览器前台与离线调用同一推进函数。保存tick及剩余毫秒，支持离线最多24小时的同规则演算，向玩家明确上限。

所有六岛在同一推进函数中更新。阶段不使用DOM时间，动画只读取真实资源流而不生造奖励。库存有容量，采矿受空闲容量限制；运输先从矿层扣量再加入地面库存；销售先从地面扣量再累计交付/资金，明确守恒。每岛记录累计开采/运输/销售与库存以供测试。

生产依次是主管/研究修正、班组阶段、协作、受限生成、按政策搬运、缓冲、按规则销售、工程状态。在线和离线同序。不将离线时间直接乘每秒收入跳过瓶颈。长期运行性能通过批量推进验证；24小时固定步可在本地执行，不能冻结UI太久，必要时分块并显示补算。

配置与研究采用合法范围检查，免费改派、方案恢复不销毁资源。存档只序列化状态；导入校验版本、岛/矿层长度、数字有限及范围、岗位唯一、配置合法后再替换。写盘失败显示提示，导出可用；无效导入不污染当前状态。无埋点上传。

## 页面

顶部资金与研究点，岛屿选择与目标；主现场竖向矿道、左侧升降机、顶部材料站，解锁更多矿层时内部列表可滚动。底部五页签：现场、调度、研究、工程、手账。调度显示三段速率/库存、预计瓶颈、岗位、节拍、物流政策和方案。设置支持声音（默认关）、减少动画、电视伴随、本地导出/导入。

工程/研究页面必须说明未解锁原因和完成条件。按钮成功后出现实际变化；失败解释缺什么。帮助解释“怎么挂机”“资源从哪来”“为什么升级后收入没提高”“怎么调度”。剧情可重读，不打断正常运行。

## 开发与完成判据

先内容表和守恒引擎，验证自然流程；再现场与功能界面；制作原创场景；注册工具页；浏览器检验竖屏触控和保存/恢复。只在这一正式策划完成后制作产品。完整作品至少满足玩法文件的六岛72层、18研究、24工程96订单、8主管和24故事；不能只完成一条采矿链就宣称完成。

持续目标：把可玩游戏制作并验证。当前研究和正式策划完成，产品开发尚未完成。数值模拟不是人类解压或好玩证据，实际视觉、操作、策略与反馈要在浏览器检查。
