# 回路暴走验收记录

验证日期：2026-10-01。本作是独立的俯视角游戏，保留上一款「裂潮」。研究与策划先于代码保存于 `docs/circuit-riot-design.md`。

## 已交付范围

- 三个开局可选角色、三张地图、六类普通敌人、精英与三个二阶段首领。
- 普通 / 过载 / 崩坏三档，八波行动，无尽每八波轮换地图并增加强度。
- 真实二维轨迹、挂线、圈内与边缘清算、截获返还、原位回声、闪避、倒带、超载与治疗。
- 24 个协议、六个有前置条件的高阶能力，暂停三选一、有限刷新、波间补给与异常事件。
- 可重玩的六步训练、五类永久强化、八项成就、统计、地图记录与角色记录。
- 独立断点和养成存档、定期保存、隐藏暂停、菜单候选恢复、结算去重、存储不可用时的内存退回。
- 手游二维摇杆与六动作按钮、构筑 / 暂停 / 自动收线 / 音效 / 配乐 / 全屏 / 震动 / 画质 / 伤害数字设置，键盘操作与横竖屏布局。
- 暂停保存返回大厅，以及主动结束并结算；无尽不必靠战败才能领取碎片。
- 参考美术的原创大厅海报、代码绘制的实时俯视战场 / 角色动画 / 轨迹 / 预警 / 粒子 / 伤害数字，以及 WebAudio 原创电子节拍。

命令：`node --test --test-reporter=dot tests/circuit-riot.test.cjs tests/neon-reaping.test.cjs`。

新作 **30 项测试通过**；上一款游戏的整个回归脚本也通过。两款游戏脚本与入口均保留。运行无需 npm 安装或构建。

## 浏览器实操

使用 Codex 内置浏览器在本地 HTTP 服务上操作实际界面，不通过页面脚本注入满级或跳过游戏状态。

- 从工具页点击「回路暴走」进入大厅，确认原创封面真实加载。
- 完整完成六步训练：摇杆移动挂线 → 收线 → 沿真实线段截获弹幕 → 原位回声 → 闪避 → 倒带 → 完成页。
- 选择折光与电弧中庭，开始正式行动，暂停保存；刷新后显示续接入口，续接后恢复原角色、原地图和种子。
- 实际摇杆、收线、闪避、自动辅助开关与设置页；检查按钮冷却 / 资源展示和暂停禁用。
- 实际战败进入结算页；同种子再战维持角色、地图、难度和种子。
- 主动结束并确认结算，领取当次碎片后返回大厅。
- 390×844 竖屏与 844×390 横屏检查。竖屏六动作触控尺寸：回声 / 倒带 / 超载 48px、治疗 45px、闪避 57px、收线 78.75px。摇杆独立，不覆盖动作按钮。
- 已修复大厅导航遮挡训练入口、技能区文字重叠、横屏训练说明遮挡角色、训练提示重复覆盖，以及无意义的波间补能购买。
- 控制台未出现游戏脚本错误。实际截图保存于 `docs/circuit-riot-screenshots/`，战场截图来自可操作的实时 Canvas；没有用海报冒充战场。

## 可验证边界

实体 Android / iOS 手机的帧率、系统音频策略、全屏支持、震动和物理多指同时输入尚未实机测试。代码使用独立 pointerId 与 pointer capture，不依赖鼠标单指替代逻辑；浏览器实操验证了鼠标模拟摇杆与各动作，未把它当作物理多指验证。

地图静态地板缓存，伤害数字与粒子有上限；低画质降低像素密度和粒子数。实际硬件表现仍需实机测量。

没有发布到远程网站或提交账号服务。所有源文件、策划、提示词与截图保留在工作区；本地预览可直接游玩。研究不支持“全球首创”承诺，本作的差异来自织线挂敌、弹幕夺取和原位重放的组合。
