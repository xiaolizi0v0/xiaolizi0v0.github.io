# 心愿成笺 · 抽卡动画收尾

2026-10-13，版本 `20261013-wish-animation-1`。用户要求「再补一个抽卡动画，游戏制作的差不多就可以了」，本次以现有可玩版本收尾，继续采用全 2D、静态独立卡面和温暖配色。

点击单抽或十连后，先完成原有抽取与存档，再播放原创心愿信封、信纸升起、星点漂浮与卡面揭晓。十连逐张点击查看，带 1/10 进度；完成后进入原有结果汇总。R 使用米杏，SR 使用柔紫，SSR 使用浅金，SP/UR 使用玫瑰与淡紫光晕；卡面保持等比裁切，显示角色、卡名、稀有度、新卡/重复补偿或碎片。

「跳过动画」在片头与揭晓阶段均可直接显示全部结果。游戏关闭动效或系统要求减少动态效果时，直接进入结果页。离开许愿页或关闭页面清理展示层、定时器和输入锁；抽取记录及已到账卡片仍由原有存档管理。展示代码不调用抽取、扣款或发奖方法；结果完成回调只执行一次。键盘 Escape 提供跳过，Tab 限定在展示层操作按钮之间。
