## 体验与循环

玩家先选择拥有的羁绊，为她安排一个想保留的瞬间；再调整相框、光影和装饰，存成方案或设为主页。主线与直播提供展示板解锁，展示本身不消耗培养资源。

| 内容 | 规则 |
|---|---|
| 晴日信笺 | 默认开放，奶油纸面与手写来信氛围 |
| 原木窗边 | 主线进度达到 6，即第一章完成后解锁 |
| 潮声留白 | 唐梨直播粉丝达到 200 后解锁，与连麦 PK 同一成长节点 |
| 展示框 | 4 种：温柔相框、拍立得、圆形回忆、拱门时光；最多 5 个，每个独立选择已拥有羁绊 |
| 羁绊展示范围 | 放大 1～3 倍，水平/垂直偏移 −50%～50%；滑杆、单指拖动和双指缩放 |
| 光影 | 4 种，最多 5 层；位置、缩放、旋转、镜像与浓度可调，浓度 10%～100% |
| 饰品 | 8 种基础素材，最多 30 件；基础装饰和相机对应信件、街景与唐梨摄影主题 |
| 素材变换 | 坐标 0%～100%，大小 35%～180%，角度 −180°～180°；复制、移除、镜像及相邻图层交换 |
| 灵感方案 | 3 个系统排版，随对应展示板解锁；保留当前主展示羁绊 |
| 我的方案 | 最多 6 份，名称 1～20 字；可新存、载入、覆盖保存 |
| 撤销/重做 | 当前编辑会话最多 30 步；拖动以完整一次手势记一步；刷新后从已保存草稿继续 |

## 界面与操作

DIY 使用独立编辑界面，隐藏城市资源顶栏与导航。返回按钮、撤销/重做、存为方案、保存展示在画板上方。画板下方显示素材数量和图层入口；选中素材后出现变换工具，精调面板提供数值滑杆。底部为展示板、展示框、光影、饰品、灵感方案五个分类。

点击素材可放入画板，也可直接拖入指定位置。图层列表可以选中被遮挡的素材。已放置素材支持拖动及键盘方向键移动，Shift 加方向键每次移动 5%；普通方向键移动 1%。

裁切面板的保存范围只影响对应相框；取消不会改变草稿。镜像相框作用于图像，框的标题仍可正常阅读。

## 保存与主页

- 草稿自动存档，保存方案产生独立快照。修改草稿不会覆盖已有方案。
- 「保存展示」将草稿应用到制作人资料中的作品预览；已启用 DIY 主页时同时更新主页。
- 「设为主页」保存展示并立即进入 DIY 主页。主页保留两侧快捷入口、八个副玩法、开始主线和底部导航，直播退出也返回该主页。
- 设置中可切换樱花城市与 DIY 主页。编辑中的新草稿不会提前改变已保存展示。
- 首版的角色选择、滤镜和饰品位置自动迁移为相框与可变换素材；原有金币、章节、卡牌、关系及直播进度保持。

真实浏览器 390×844 操作确认：选择唐梨卡牌并切换拍立得；裁切放大 1.2、水平偏移 1%；饰品缩放到 75%、旋转 5°、复制与镜像；拖动后撤销和重做恢复相同坐标；新增第二相框并独立更换羁绊；光影浓度保存为 60%；图层列表选择素材；保存并载入「唐梨 · 晴日来信」；设为主页、进入直播再退出、刷新恢复；从素材栏拖入丝带，只新增一件并保存落点。

## 尚有差距

本轮补齐 DIY 的上述编辑操作，不代表原作所有系统已完成。相框采用本项目 6 位角色肖像，没有原作全部独立 CG、动态展示板、商业礼包和联动素材库；首轮「个人展示」仅本地预览；2026-10-10已扩展到在线好友空间，见下方追加。双指裁切逻辑已实现，当前浏览器鼠标验收不能等同实体手机多点触控验收。
