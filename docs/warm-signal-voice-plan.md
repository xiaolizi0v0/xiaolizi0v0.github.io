## 本次选型

采用 **Qwen3-TTS 12Hz 1.7B VoiceDesign + Base**。VoiceDesign 根据原创角色描述产生参考音频；Base 使用这段合成音频和准确文本固定声线，生成后续对白。电脑制作阶段调用官方 `qwen-tts` SDK，预先输出 MP3；手机只读取随游戏提供的录音。游戏中没有模型地址、实时合成请求或本地配音服务依赖。

| 方案 | 适用性 | 本次决定 |

## 手机方案与当前范围

- 13 份原始 WAV 和对应试听 MP3 已生成。“制作人资料 → 设置与存档 → 声线试听与设置”支持女生、男主/旁白、配角筛选。
- 主线全部 1121 条台词及分支回应已建立制作索引，其中 1118 条不同的角色/文本组合。已全部离线录制，包含所有分支回应；旧存档短版剧情也已补录。
- 其他固定对白也已建立离线索引，包含约会、SP、UR、约期、拍摄副本、传闻、手机内容、漫漫夜话与她的心声，本次复查又补齐生日与盛装、小屋回忆及互动、晴川城市故事、两卷迷宫、公司约会与工作来信、直播回应、城市漫步、宠物家庭、UR互动、睡眠触摸与陪伴运动回应。连同旧版主线共 4071 条不同的角色/文本组合，已全部录制。它们的索引在 `voice-extra-script.json`。
- 播放器只播放 `voice-lines.json` 中登记的 MP3，以及 13 条角色试听。未录制的句子提示“本句配音尚在制作”，继续阅读不受影响，绝不请求模型。
- 手动翻页或退出时停止上一句；旧播放回调不能覆盖新角色。自动阅读等待当前录音结束，配音时背景音乐自动降低，结束后恢复。
- 人声音量与开关使用独立设备设置，不写入游戏资源或导出存档。手机无需安装模型、设置电脑 IP 或提供 TTS 密钥。
- AI 自由聊天内容由玩家即时产生，不能提前录制。它继续使用文字回复，可自行选择手机的设备朗读；该选项与角色的预录声音分别标明。

截至本轮，全部已索引固定对白合并去重后为 **5187 条 MP3**，约 **313.1 MB**、约 **7 小时 7 分钟**。网页按当前台词加载，不预先下载整套录音；参考 WAV 和模型权重不由手机播放器加载。完整性、文件哈希和分系统覆盖记录在 `voice-release-manifest.json`。

## 本机运行与耗时


RTX 5060 Ti 16GB、32GB 系统内存，Python 3.10、Torch 2.9 CUDA 12.9、qwen-tts 0.1.1，BF16 + SDPA。本轮复用已有官方模型缓存和 Python 环境，只读取其文件；新声线、服务代码和生成缓存属于 Warm Signal，没有修改另一个游戏的角色音频、模型或依赖。

- VoiceDesign 参考模型约 4.52 GB；Base 约 4.54 GB，权重不放入仓库。生成参考后卸载 VoiceDesign；离线批量制作时只加载 Base，结束即退出。
- VoiceDesign revision：`5ecdb67327fd37bb2e042aab12ff7391903235d3`。
- Base revision：`fd4b254389122332181a7c3db7f27e918eec64e3`。
- 序章新台词首次 Base 合成实测约 9～27 秒，短句冷启动也可能较慢。陆伯新对白实测 15.30 秒，音频为约 5 秒。重复播放走缓存。
- 未安装 flash-attn / SoX 的提示在本机这组调用中未阻止推理。没有为此修改共用环境。

制作工具只在开发电脑运行，不随手机游戏启动：

```powershell
node ./tools/warm-signal/build-voice-script.cjs
node ./tools/warm-signal/build-voice-extra-script.cjs
& "$env:USERPROFILE/.codex/cache/after-rain-voices/venv/Scripts/python.exe" ./tools/warm-signal/prerender-voices.py --batch 64 --scope all
```

`--scope main` 只制作主线，`--scope extra` 制作其他固定对白及旧版主线，`--scope all` 制作全部已索引固定对白。脚本按已有 MP3/索引断点续作，权重路径可用 `--model` 指定；新文件自动登记在 `voice-lines.json`。参考声线由 `generate-voice-cast.py` 制作，已有参考不会重复生成。波形解码按 4 条分组、MP3 编码使用 4 个工作线程；每批释放闲置显存，避免长批次累积占用。所有工具离线加载官方缓存，本轮没有下载新权重或配置新的网络代理。

复查页：`tools/WarmSignalVoiceAuditReview.html`；它调用实际 UI 模块的播放入口，使用独立内存存档。

模型生成只发生在这台开发电脑；原先用于验证的本地实时配音服务已经停止，服务代码和启动入口已撤除。手机页面只使用静态配音资源。试听页：`tools/WarmSignalVoiceReview.html`，它使用内存设置，不改正式游戏存档。

## 验收与后续

本次 391 项配音、BGM 与相关玩法检查通过，另有 1 项既有充值迁移检查保持跳过。新增实际 UI 调用检查覆盖拍摄副本、生日、小屋、两卷迷宫、公司、晴川故事、睡眠、UR、漫步和宠物；新增跨人物语音队列的顺序与取消检查。覆盖 13 位主线说话人路由、独立参考 WAV 哈希、男主/旁白/NPC 试听、快速切换的迟到播放回调、缺失录音不调用模型、不阻断阅读、未知人物拒绝，以及序章全部预录文件。BGM 专项验证人声降低与恢复音量。没有运行模拟充值测试。13 位角色试听均在浏览器实际解码播放，320/390 CSS 像素宽 iframe 布局无横向溢出。没有在物理手机上测试。本次使用独立内存存档验证，未读写正式游戏存档。11 种新增入口在浏览器均实际解码播放；这不代表逐句人工听审。

2026-10-14 复查发现上轮 3727 句清单未涵盖所有玩法，且拍摄副本漏接 `voicePlayer` 变量；已修复，增加 1460 份预录音频。新增文件的时长、振幅、哈希和参考音色一致性均通过检查。打开弹窗、切换段落与退到后台会取消尚未播放的语音队列，自动漫步等待当前语音结束。详见 `docs/warm-signal-screenshots/voice-audit-v2/`。

声音仍标记为 `audition`。后续应人工听审 13 人音色、发音、断句和重复字，不合适的角色重新设计参考后再批量录制。Base 使用固定参考音色，不承诺逐句精准控制哭腔、笑声或情绪强度。已建立制作索引、已输出录音和已人工听审是三个不同状态，不能混称为完整精修配音。
