局域网大模型跨域与访问诊断

因为本博客部署在 GitHub Pages (HTTPS)，当直接请求您本地局域网的大模型（如 http://10.21.1.45:26199/v1 或 http://127.0.0.1:11434）时，现代浏览器会默认触发 Mixed Content（混合内容拦截） 和 CORS（跨域限制）。

方案一：启动仓库自带的本地代理（最稳定·支持流式，推荐）

仓库内已自带原生 Node.js 流式转发代理脚本，可一键转发局域网请求并追加完整 CORS 跨域头：

  1. 在本地项目根目录的 worker-proxy/ 文件夹中；
  2. 双击运行 start-proxy.bat；
  3. 代理服务启动在 http://127.0.0.1:25100。在「模型设置」中将代理模式选为 「本地代理转发」 即可畅通无阻！
双击运行：worker-proxy/start-proxy.bat

方案二：浏览器设置放行混合内容（无需启动任何代理）

直接告诉浏览器放行当前 GitHub.io 网站的不安全 HTTP 资源请求：

  1. 点击浏览器顶部地址栏最左侧的 🔒 图标；
  2. 点击 「网站设置 (Site settings)」；
  3. 在权限列表中找到 「不安全内容 (Insecure content)」，由「屏蔽」改为 「允许 (Allow)」；
  4. 回到本网页按 F5 刷新，即可直接直连局域网 http://10.21.1.45:...！
