# 热搜清屏

竖屏自动割草与舆论噪声机制，入口为 `../HotSearchReaping.html`。从热搜点入话题战场，或通过固定战役解锁永久成长。完整策划见 `../../docs/hotsearch-reaping-plan.md`。

## 游玩

- 默认自动走位、自动攻击、自动技能；摇杆/WASD临时接管，松开恢复自动。
- 查证/Q消耗25上下文并破盾、压制扩音；降温/E降低压力并减速；置顶/空格满能量清场；Shift闪避。
- 工坊调整三名角色、八种武器的四槽组合、12项永久研究及三组配置。自动推进可关闭，提供1倍/2倍节奏。
- 六章36关、六种首领机制、12段插画故事、16项成就。第一章完成后解锁无尽。
- 本地存档含正在进行的战斗；支持校验后导入、导出。离线按已通关记录最佳收入速度的35%结算，最多8小时，不代打未通关首领。

## 热搜服务

数据只读，来自微博匿名公开接口 `https://weibo.com/ajax/side/hotSearch`，不使用登录凭据。通过 `node feed-service.cjs` 启动在127.0.0.1:8767的固定目标服务；前端在localhost自动尝试连接。普通读取最多两分钟一次，手动刷新有15秒间隔，错误时返回带原读取时间的快照。

`node refresh-feed.cjs` 可单独刷新同目录的 `feed.json`。静态部署没有后台服务时，明确显示官方快照及读取时间；游戏、战役和成长仍可用。尚未配置或发布远程刷新服务。

真实热搜不受战斗成绩影响。个人“游戏战报”按实际话题清屏数量排名。真实榜位升降比较两次读取中相同标题的排名，首次读取显示横线；热度数字、行位、热度条和入场动效响应减少动态设置。

## 验证

`node tests.cjs`：15项因果与存档检查。

`node progression.cjs`：从新存档使用实际收入购买升级，走通36关；结果保存为 `progression-results.json`。当前结果为3544秒游戏时间、36次胜利、26393次清屏；另完成360秒无尽、13波、三个首领。此结果证明可达性，不代表真人对可玩性的评价。自动购买仅存在于验证脚本，玩家端由玩家选择研究。

`review-save.json` 是该合法模拟产生的审核存档，用于检查后期界面，产品不会自动读取。

实际浏览器验证记录见 `../../docs/hotsearch-reaping-verification.md`；`?review=1` 使用独立测试存档，正常入口的成长不受后期审核导入影响。竖屏榜单、战斗截图分别为 `../../docs/hotsearch-reaping-preview.jpg` 与 `../../docs/hotsearch-reaping-battle.jpg`。

图片通过图片生成制作，六张剧情/场景图及人物、首领图集都在 `assets/`。实时人物剪裁仅发生于Canvas显示，不修改原图。
