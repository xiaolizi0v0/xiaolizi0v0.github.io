# 死神VS火影 HD：重制版 (Bleach vs Naruto HD Rebirth)

专为手机浏览器优化的 2D 格斗引擎高清重制版。入口文件为 `tools/BleachVsNaruto.html`，已无缝接入个人博客「工具箱」页面。

---

## 1. 开源出处与技术沿革

本项目复刻自著名国内同人格斗游戏作品**《死神VS火影》**（Bleach vs Naruto，简称 BVN）。
- **官方开源团队**：5DPLAY Game Studio（制作人 **剑jian** 及其团队）
- **官方开源仓库**：
  - Gitee: [play5d_game_studio/BleachVsNaruto](https://gitee.com/play5d_game_studio/BleachVsNaruto)
  - GitHub: [5DPLAY-Game-Studio/BleachVsNaruto](https://github.com/5DPLAY-Game-Studio/BleachVsNaruto)
- **原版技术栈**：早期原版基于 Adobe Flash / ActionScript 3.0 开发，美术资源多为 96x96 ~ 120x120 像素位图。随着 Flash 停更，传统 SWF 在移动端和现代浏览器上无法直接原生运行。
- **重制版升级**：使用纯原生 HTML5 2D Canvas + Web Audio API 进行物理与格斗判定引擎全栈重构，并针对手机触屏量身定制虚拟多向摇杆与技能轮盘，无需外部 Flash 插件或重型 WASM 运行时，即点即玩、零加载延迟。

---

## 2. 美术素材高清重制技术 (HD Remastering)

为了解决经典像素/低清 Flash 位图在现代手机 1080P/2K/4K 屏幕上马赛克明显的问题，重制版实装了四大核心图形与艺术提升技术：

1. **神经网络超分辨率插值 (AI Super-Resolution)**
   - 引入动漫特化神经网络（基于 Waifu2x 与 Real-ESRGAN 二次元重构模型）对经典角色动作帧进行边缘超分辨率重构与降噪放大，彻底抚平低分辨率噪点与锯齿。
2. **亚像素矢量描边与着色 (Subpixel Vector Cel-Shading)**
   - 2D Canvas 采用 subpixel 亚像素级贝塞尔平滑曲线重绘角色轮廓、发丝与刀刃光芒，在视网膜屏幕上始终保持刀刻般的清晰度。
3. **动态 HDR Bloom 发光与多层视差场景 (Dynamic Glow & Parallax Stages)**
   - 月牙天冲剑芒、千鸟雷暴电弧、螺旋丸风涡气旋与天照黑炎采用叠加色彩光晕混合管线；
   - 包含 4 张超清视差对战舞台：木叶·终末之谷、尸魂界·双殛之丘、木叶·演习场、虚圈·虚夜宫穹顶。
4. **动漫张力冲击定格帧 (Anime Impact Frames)**
   - 关键奥义与暴击命中时，触发 2 帧高反差黑白负片冲击定格，配合 Web Audio 合成的深沉低频震鸣，完美复刻热血漫打击冲击力！
5. **画质实时对比系统**
   - 顶栏一键切换「✨ AI超分重制」与「👾 原版低清像素」，可在对战与道场中直观对比重制前后的画质飞跃。

## 4. 操控方式

### 手机触屏操作 (优化人机工学)
- **左侧虚拟摇杆**：全向移动、推上跳跃、下拉蹲防、双击左右疾跑瞬步。
- **右侧弧形战斗按键**：
  - `普攻 J`（主键位，支持 3 段普攻连打）
  - `跳跃 K` / `瞬步 L`
  - `技能 U` / `特技 I`（耗能量 30 点）
  - `奥义 O`（耗能量 100 点 / 1 条气，触发大招全屏震撼动画）
  - `援助 P`（召唤援护伙伴协同作战）
  - `替身`（受击受创僵直时瞬移脱离，消耗 80 点能量，CD 10 秒）
  - `觉醒`（满能量爆气变身 15 秒，攻击力与移速大幅强化）

### 电脑键盘操作
- `A` / `D`：左右移动
- `W` / `K`：跳跃
- `S`：下蹲防守
- `J`：普攻（三段连击）
- `L`：瞬步 / 闪避
- `U`：技能
- `I`：特技
- `O`：奥义必杀
- `P`：呼叫援助
- `空格`：替身术脱离
- `Q`：爆气觉醒
