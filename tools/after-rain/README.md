## 本地视频流程

ComfyUI安装在用户Codex缓存的独立`after-rain-video`目录，继承原有`torch5060`GPU库，新增依赖只安装在独立venv。官方最新模板包要求更高Python版本，因此用手动下载的官方原生Wan工作流，不安装模板媒体和GLSL扩展。核心Wan、视频保存节点已通过HTTP节点清单检查，尚待模型下载完成后的真实推理验证。

`download-video-models.py --comfy <路径>`仅下载官方三个模型并校验SHA256。模型版本记录在`video-model-status.json`。下载过程中独立text_encoders和vae状态文件用于并行准备。模型不放网站仓库。

`queue-wan-shot.py`上传本项目原创首帧到本机127.0.0.1:8188，提交一次有限的图生视频任务并保存完整参数。默认低分辨率只用于连通性测试，正式镜头需提高到704×1280及以上并通过视觉审阅。任何候选镜头都不能自动标记成品。

## 运行和验证

任意静态服务器即可预览，无Node依赖和远程业务服务。三手动槽、自动进度、回溯、台词回看、关系事实、通告、拍摄笔记、消息回复、已读跳过、音量/字幕/减少动态设置可用。

`node tests.cjs`验证首选因果、回溯还原、坏档拒绝、第一章全部72条路径。`node export-script.cjs`重建脚本清单；`node production-audit.cjs`生成实际制作统计。修改对白后必须重新生成摘要对应的配音。
