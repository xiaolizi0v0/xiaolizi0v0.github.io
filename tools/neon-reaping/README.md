# 裂潮：霓虹清场

博客工具页的独立手机浏览器横版动作割草游戏。入口：`tools/NeonReaping.html`；工具列表配置：根目录 `data-config.js`。

无需 npm、后端、CDN、账号或付费 API。可直接打开 HTML，也可通过任何静态 Web 服务器运行，GitHub Pages 可直接承载。大厅角色海报约 2.6 MiB，只加载一次；图像不可用时有 Canvas 绘制的备用主视觉。

## 玩法

- 三位英雄：近战零刃、枪手火花、冰霜法师霜棘；未解锁英雄可免费试玩。
- 三章各六波，三种双阶段首领，六种敌人；普通、困难、极限与首领循环的无尽模式。
- 24 项局内协议，六种自动武器及觉醒搭配。首次升级保证提供一种自动武器，每三次等级成长优先提供已有武器。
- 持续压制裂隙，完成击杀配额并击破精英 / 首领进入补给；战斗中捡取经验升级，暂停选择三选一。
- 永久强化、英雄解锁、每日任务、八项成就、战斗统计、本地断点存档。

## 操作

手机使用水平摇杆与七个战斗按钮：普攻、二段跳、平台下落、闪避、技能、超载、治疗。可多指同时操作；辅助自动攻击可以关闭。顶部提供暂停、构筑、音效与全屏按钮。

电脑：A/D 或 ←/→ 移动；J 普攻；K 或空格跳跃；S 或 ↓ 下落；L 或 Shift 闪避；U 技能；I 超载；H 治疗；Esc/P 暂停。普攻可按住。

战斗记录每五秒和状态切换时写入 localStorage，页面隐藏自动暂停。升级候选和刷新次数也保存。游戏进度按设备与浏览器保存；清理站点数据会清除进度。

## 实现与维护

- `data.js`：角色、章节、升级、觉醒条件、永久强化、成就数值。
- `game.js`：战斗状态机、物理、碰撞、敌人预警、武器、Web Audio、菜单、存档、原创 Canvas 美术。
- `game.css`：斜切荧光风格大厅与横竖屏触控布局。
- `lobby-art.png`：内置 imagegen 生成的原创大厅角色海报。
- `cover.svg`：工具页原创封面。

策划与最终主视觉提示词分别在 `docs/neon-reaping-design.md` 和 `docs/neon-reaping-art-prompt.md`。无需构建；调整数值后运行：

```sh
node --check tools/neon-reaping/game.js
node tests/neon-reaping.test.cjs
```

测试使用真实引擎，包含击杀与掉落、三角色技能、无敌帧、二段跳、下落、多指取消、武器觉醒、刷新存档、补给限购、首领二阶段、奖励去重、试玩隔离、暂停、无尽与章节结算，以及基于实际攻击 / 冷却 / 生命的五次完整通关模拟。测试接口仅在显式 `window.__RIFT_TEST__` 为 true 时公开，常规页面只提供只读状态诊断。

## 已验证与实际限制

已在 Chromium 浏览器检查大厅、战斗、升级、技能、暂停、设置、结算、继续存档、工具入口，以及 844×390 / 390×844 两种手机尺寸。未在真实 iOS / Android 硬件上进行触摸、耗电和长时间性能测量。全屏、锁屏方向和震动取决于浏览器支持；不支持时保留正常游玩。

画面美术取参考截图中的色彩与斜切动感，人物、名称和内容为原创。游戏为单机网页作品，不含联网对战、充值、排行榜服务器或账号云存档。
