# 心动来信 · WARM SIGNAL

男主视角的原创单机恋爱经营游戏，入口为 `tools/WarmSignal.html`。使用原生 HTML/CSS/JavaScript，可直接放在 GitHub Pages；无构建或真实付费。单机玩法无需账号；好友为可选独立Python服务，大模型聊天按玩家配置连接外部服务。

2026-10-13 收尾版新增「心愿成笺」抽卡动画：信封片头、稀有度光效、十连逐张揭晓、跳过和减少动态效果。主页可直达全 2D 晴川街区，票房编队支持实力排序。更新现有页面后即可体验；抽卡动画使用已经保存的结果。策划与验证见 `docs/warm-signal-wish-animation-plan.md`。

同日加入三首 Scott Buckley 的 CC BY 4.0 背景音乐：Childhood、Elementary、Reverie，按日常/剧情/陪伴场景自动切换。主页「♫ 音乐」或设置中可选曲、暂停和调音量，首次点击页面后开始。录音、署名和来源随游戏分发；详见 `docs/warm-signal-bgm-plan.md` 与 `assets/music/CREDITS.md`。

## 游玩

python -m http.server 8765 --bind 127.0.0.1

## 当前视觉方案：静态立绘＋轻量动效

用户已选择先不做 Live2D。六人十八套服装使用完整静态插画，人物使用整体淡入、轻微呼吸位移、互动心形，并按用户补充保留眨眼压缩和嘴部拉伸；唐梨日常/居家两套升级为独立 1024×1536 透明立绘。换装、聊天、场景和计时存档继续使用。轻量 WebGL 只处理眨眼与嘴部，不继续拆层或正式 Live2D 绑定；关闭动效或设备不支持时显示原始静态立绘。完整策划与出图提示词见 `docs/warm-signal-static-art-plan.md`；`models/tangli/preview.html` 可检查两套高清原画及开关轻量动效。
