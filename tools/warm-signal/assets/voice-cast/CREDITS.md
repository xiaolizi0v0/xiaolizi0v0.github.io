# Original synthetic voice cast

These thirteen character voices were generated for Warm Signal from original adult-character descriptions with **Qwen3-TTS-12Hz-1.7B-VoiceDesign**. No real-person, voice-actor or commercial-game character reference recordings were used.

Fixed dialogue is rendered offline with **Qwen3-TTS-12Hz-1.7B-Base** using these synthetic references. The mobile game plays prerecorded MP3 files; it does not run or contact a TTS model.

Models: Qwen Team, Apache-2.0 as stated on the official model cards. Model source: https://github.com/QwenLM/Qwen3-TTS

- VoiceDesign: https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign
- Base: https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base

Casting descriptions and seeds: `../../voice-casting.json`.
Reference text, sample durations and WAV SHA256 hashes: `../../voice-cast-manifest.json`.
Prerecorded dialogue index: `../../voice-lines.json`.
Production status and MP3 hashes: `../../voice-production.json`.

Audio status is an audition, pending human listening and pronunciation review. Descriptions state intended vocal qualities, not verified perceptual judgments.
