# 回路暴走 / CIRCUIT RIOT

独立的俯视角 2D 肉鸽割草游戏。入口 `tools/CircuitRiot.html`，已接入博客工具页。没有横版平台或固定射击方向，二维摇杆支持八向自由移动。

## 游玩

在工具页选择「回路暴走」，先完成可重玩的六步训练。选择三种角色、三张地图、三档难度；普通行动八波约五分钟战斗，包含升级、补给与异常合约。无尽每八波更换地图并增强敌人。

移动留下轨迹，敌人穿过后挂线，弹丸穿过后被截获。收线把末端和起点连接，清算圈内、边缘和挂线敌人，释放夺取的弹幕。回声在真实旧坐标重放，不追随玩家。倒带回到本卷起点，取消轨迹并回收线能。红色区域是攻击预警，烧损线段不再挂线或捕弹。

另有构筑查看、音效、原创电子节拍、自动收线辅助、全屏、伤害数字、画质与震动设置。暂停时可保存稍后继续，也可主动结束并结算，包括无尽行动。三角色开局都可选，五类永久强化与八项成就使用本地义体碎片。

## 构筑

- 几何：宽刃、接缝、大面积与延长线卷。增幅 + 宽刃达到二级解锁常驻裂域；面积 + 线卷解锁镜像。
- 夺弹：容量、反射、充能与截获恢复。容量 + 充能解锁双倍追踪弹；反射 + 接缝解锁三相传导。
- 回声：增幅、短冷却、旧影诱饵与停帧。回声 + 记忆解锁双重曝光；倒带 + 诱饵解锁逆时剪辑。
- 机动：闪避、倒带、线能与活性装甲，配合免费回声和异常合约。

## 技术与验证

无需构建与第三方游戏引擎，HTML / CSS / Canvas / WebAudio。规则层与界面分离，可以在 Node 中测试真实几何、战斗、升级和存档。静态文件可直接部署到现有 GitHub Pages；未自动推送或发布。

`node --test tests/circuit-riot.test.cjs` 执行 30 项规则与完整行动测试，包含凹多边形与交叉闭环的真实区域判定。

`node tests/circuit-riot-bot.cjs` 输出四种构筑的完整通关报告。控制器只使用正常移动、技能、候选选择和购买，不注入无敌、无限生命或满级构筑。

存档键为 `circuit-riot-profile-v1` 与 `circuit-riot-run-v1`，与「裂潮」独立。正式行动每五秒和流程切换时保存，训练不写正式断点。升级和事件候选会保存，结算按行动 ID 去重。浏览器禁止存储时退回当前页面内存。

策划、研究来源、美术提示词与验证边界位于 `docs/circuit-riot-*.md`。大厅 PNG 由内置 imagegen 生成；实时战场与精灵由 Canvas 绘制。
